# B1三种子实验：数据分析与后续方向

分析日期：2026-11-01。基于本批次18份原始报告、summary.json、既有实验矩阵与当前融合模块源码。只做结果分析，不改变训练协议或启动实验。

## 1. 核心判断

A表示局部/全局固定1:1通道分工+SR2；R表示原纯SSM骨干+原融合+平均池化。

在A之上，独立扫描、整段拼接、交错扫描均未取得平均OA提升。不能将现有A+B1作为已验证的性能提升创新。R+B1则在三个种子上均有正增益，但平均OA仍比A低1.3992个百分点；它是可保留的研究线索，尚不足以替代A。

## 2. 配对证据与控制实验的意义

| 比较 | seed6/7/8 OA差值，百分点 | 平均差值，百分点 |
|---|---|---:|
| A+B1 − A | −0.4919 / +0.0082 / +0.1230 | −0.1202 |
| A+独立扫描 − A | −0.0984 / +0.1886 / −0.1066 | −0.0055 |
| 整段拼接 − 独立扫描，在A上 | +0.0492 / −0.0820 / +0.0410 | +0.0027 |
| 交错扫描 − 整段拼接，在A上 | −0.4427 / −0.0984 / +0.1886 | −0.1175 |
| R+B1 − R | +0.0574 / +2.1973 / +0.5575 | +0.9374 |

独立扫描控制提示单纯增加该SSM模块在A上没有平均收益；整段拼接与独立扫描近乎持平；交错扫描亦未优于这两个控制。三个种子的微小平均差不能视为方法等价证明。

A+B1的seed7增益只对应1个测试样本，seed8对应15个样本，seed6少60个样本。不能仅凭“2/3种子提升”判为整体成功。

R+B1三个种子的额外正确样本数分别为7、268、68；平均增益受seed7影响较大。R+B1的OA标准差0.7963高于R的0.5493，不支持“稳定性提升”的表述。

交互项 `(G04−G01)−(G05−G00)` 三个种子均为负，平均−1.0576个百分点。支持B1的效果依赖所处模型配置；信息冗余、优化干扰等只是解释假设。A同时改变特征提取与池化，本批次不能把该现象归因到局部/全局分工或SR中的任意单项。

R侧没有独立扫描与整段拼接的对应控制，因此R+B1的收益尚不能单独归因于交错顺序，也可能涉及新增容量或额外特征变换。

## 4. 后续研究优先级

1. **先明确B1为何与A不兼容。** 如研究目标仍是改进A，可复用原流程M1（仅局部/全局分工）和M2（仅SR2）的既有6/7/8结果，后续审核两组：M1+B1、M2+B1。每组三种子，共6项新训，可补齐“分工×SR×B1”的组合，对B1增益在哪个环节衰减作更明确定位；不重复训练原27项。
2. **面向A探索按位置或通道选择的交互。** 当前模块已经有两支可学习标量残差系数，不能把“加一个标量门控”重复当新创新。可研究依据两模态特征一致性、差异或局部上下文生成位置/通道权重，减少不必要的信息交换。信息可信度、边界保护效果均需验证，不能从当前类别统计直接认定。机制应不依赖测试标签，训练入口与损失协议沿用原代码。
3. **若转向R+B1，先补其自身控制。** 需要R+独立扫描、R+整段拼接，才能检查R上的收益是否特属于交错扫描。若两者同样改善，创新叙述应落在额外融合变换，而非交错次序。

优先选择与研究目标相符的一条路径，避免同时铺开全部实验。后续采用位置/通道门控时，应将其与现有标量B1及匹配容量的控制比较，并同时检查OA/AA/Kappa、商业区精确率与召回率、道路/住宅类别代价以及参数/计算开销。

本轮不支持继续把增加扫描层数或增加扫描次序作为主要创新。只修改交错顺序的收益尚无证据，先解决信息选择与模块配合更有针对性。

## 5. 论文表述边界

可以写：在Houston2013既定原流程下，交错扫描在原骨干上获得三种子一致的正向OA差值，但未与局部/全局分工+SR2组合形成平均性能增益；类别分析显示收益与误报之间存在取舍。

不能写：A+B1有效提升精度、交错扫描普遍优于其他扫描、稳定性改善已证实，或跨模态噪声/过平滑机制已经被验证。当前仅有三个种子，原测试OA参与选模；不能据此声称统计显著、跨数据集泛化或独立测试收益。
