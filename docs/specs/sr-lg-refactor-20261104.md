# SR配合固定1∶1通道分工的重构规格

## Goal

交付一个可以审查、CPU预检和后续按原流程训练的候选，解释现有证据。目标是检验能否提高SR条件下的整体精度并保住道路类收益，不在训练前承诺最优性能。

## Problem Statement

既有LG＋SR平均OA89.3990，GG＋SR为89.4100，LL＋SR为87.5243。混合仅在道路等类别有优势；原分支一条保留SSM输入残差，一条直接使用卷积输出，更新尺度也不同。这些是实现事实，不是已证实的性能根因。缺少GG不加SR的对照，不能从现有结果认定SR特别适合全局。

## Context From Memory

已检索MEMORY.md的SR／固定1∶1约束，并核对当前原生报告、机制归档及代码。项目没有根SPEC.md和docs/knowledge-base；spec-index默认知识库无可用记录。已有B1尝试过局部残差，P01尝试过注意力SR先验，本次不能将它们重新命名为新发现。

## In Scope

- 新增独立模型目录、标准adapter、CPU行为预检、12项待审核配置与矩阵。
- 候选：两路固定32通道；保留原SSM、原注意力和原局部卷积；两路残差对称化；局部输入和两路更新做LayerNorm；用SR加权的两路更新摘要预测两个样本级增益。
- 增益采用2×sigmoid，初始为1，保持32／32分流，允许降低或增加某一路的更新，不重新分配通道。
- R01：用平均摘要的等参数版本；R02：正确SR摘要候选；R03：只错位摘要、末端SR正确；R00：复用GG算子、末端平均汇总。
- 保持既有代码字节与checkpoint路径；提供空闲且完成审查后才能执行的注册工具。

## Out Of Scope

- 不更改训练循环、数据、PCA、划分、增强、优化器、损失、选模、指标及SR2公式。
- 不启动未经审核的新训练，不抢占另一个已批准训练批次的GPU，不改它封存的注册表。
- 不搜索其他通道比例，不新增PN／OC／蒸馏方向，不重跑历史27项。

## Constraints

Houston2013、PCA30、11×11、100轮、batch128、AdamW学习率1e-4与wd0.01、seed6／7／8；仍使用scripts/train.py及原生训练／评估链。原测试OA选模只支持探索性比较，不是独立测试。

## Assumptions

- 用户授权实现一个新候选；新训练仍须按AGENTS.md先审核具体矩阵。
- SR权重仅由输入计算，不使用标签；末端SR不变。
- 另一个批次正在训练，当前只做独立CPU合成输入验证；真实数据batch／GPU预检须待空闲。

## Blocking Questions

实现无阻塞问题。正式训练需要审核12项矩阵，并等现有批次结束；这不阻塞代码和配置交付。

## Acceptance Criteria

- 新模块不消耗额外的调用者随机数状态，共享原层初始参数与原模型逐项相同。
- R01／R02／R03参数数量和初值完全相同；零初始化增益头使初始输出相同。
- R02和R03的末端SR与原SR2相同；只有摘要使用的位置对应关系不同。
- 增益头非零时，SR摘要和平均摘要能实际改变输出；不能有名无实。
- CPU标准adapter前向／反向通过，增益头有梯度，梯度有限；batch128接口通过；整模型保存加载通过，加载后改变batch尺寸不会沿用旧上下文。
- 无标签输入模型；只使用原数据入口进行未来真实数据预检。
- 全部已有批次封存文件SHA不变；新模型当前不写入注册表。
- 配置唯一命名，不覆盖现有结果，所有新组均使用三个种子。

## Edge Cases

错误模式、非11×11输入、缺失／非正SR参数、通道数或dataset不符应报错。运行注册工具时若有训练／控制器仍活动、审批缺失、模型名冲突则拒绝写入。

## Validation Plan

执行scripts/check_sr_lg_refactor.py（CPU，固定合成输入，无优化器或科学训练）；逐项检查源文件与活跃批次锁定文件哈希。正式启动前还需原getMyData的真实batch128、GPU及整模型原生评估预检。

## Execution Plan

1. 新增模型、adapter及CPU检查；复用现有GG替换器和SR实现。
2. 准备R00–R03每组seed6／7／8配置、具体审核矩阵和分析说明。
3. 给出真实的检查结果和未验证项；提交具体矩阵供审核。
4. 审批且GPU空闲后才注册模型，另按原入口执行；不因单种子成绩继续加组或调参。

## Open Questions

真实训练是否提高OA、道路收益是否保留、增益是否学成有效的样本依赖差异，均为待验证科学问题。R01把残差、尺度校准和平均摘要门控作为一个重构整体，不能拆解这三项的独立贡献。

## Self-Check

Ready for implementation。实现允许；训练审批与并发条件明确。验收不包含“保证最优”，不以降低标准通过失败检查；必要修复遵循同一规格，不写长期记忆。
