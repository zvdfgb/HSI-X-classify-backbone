## 目标与已有约束

优先使用实验室已有 `scripts/train.py → ExperimentRunner → src/trainer.py → src/evaluator.py`。不使用 `src/fusion_experiment.py`；不重写数据划分、优化器、训练循环、评估及 checkpoint 规则。原三方法批次 `lab_fusion_20261025_133847` 必须先完成并封存源码核验，之后才能添加蒸馏接口。

历史记忆指出旧 B0 约 88.9727、旧本地 CNN 89.60、RSCNet 90.01；这些仅用于选择候选教师。教师必须在本轮相同实验室协议下重新训练。现有项目知识库未检索到已实现的蒸馏方案。

## 预先固定的实验组

全部 Houston2013、seed6、100轮、官方2832训练／12197测试、PCA30、窗口11、batch128、AdamW lr0.0001 wd0.01；保留旧测试准确率选模，明确为探索性协议。CPU OMP/MKL线程统一4。学生均从头训练，不延长训练、不增加测试评估次数、不按学生测试结果调蒸馏超参数。

| 组 | 模型与训练 | 作用 |
|---|---|---|
| F0 F1 F4 | 已运行的原版 B0 直接融合、F1、F4 | 复用原三组，避免重复训练 |
| T1 | 实验室原生 RSCNet | 主教师和本地强方法基线 |
| T2 | 实验室原生 CNN | 第二教师；与学生同样使用 PCA HSI 和辅助模态 |
| K1 | 原 B0 学生向 RSCNet 蒸馏 | 蒸馏是否能改善直接融合 |
| K2 | F4 学生向 RSCNet 蒸馏 | 蒸馏能否与交互叠加 |
| K3 | F4 学生向 CNN 蒸馏 | 教师选择对照 |
| K4 | F4 向 RSCNet 蒸馏，仅使用教师置信度≥0.7的样本 | 检查错误知识过滤假设 |
| C1 | F4 标签平滑 epsilon0.1，不加载教师 | 软目标正则化对照 |

共新增7次正式训练，两次教师、四次蒸馏、一次平滑。固定温度T=4、蒸馏系数lambda=0.3；损失为 `L = 原CE + lambda * T² * KL(教师概率 || 学生概率)`。过滤组以温度1的教师最大概率判断，仅在接受样本上平均KL；全拒绝时只使用CE。平滑组使用CE(label_smoothing=0.1)。这些值是预先固定的探索参数，不声称最优。

RSCNet 输入还包括原始144波段 HSI，属于训练阶段可用的更丰富信息；CNN只接收与学生相同的PCA HSI和辅助模态。两种教师比较同时涉及网络结构和信息量，不能据此孤立证明某一种结构更适合当教师。推理时只保存学生原网络，不保存教师，不增加学生参数量。

## 实现与验收

1. 先验证当前三方法完整结束，封存原报告、指标、checkpoint路径、训练日志及当时源码哈希。旧批次不重训、不覆盖。
2. 仅在现有训练器增加可选 adapter `compute_loss` 与训练结束诊断回调；默认仍直接调用原CE。配置新增可选蒸馏字典、注册蒸馏适配器。优化器仍只接收学生net.parameters。
3. 所有教师独立训练后固定、eval、无梯度。教师读取同一个增强后的 batch，禁止错位缓存；训练结束校验教师参数及BN状态没有变化。
4. 保持学生初始化和推理接口；蒸馏权重0应与原CE完全一致。教师不进入学生state_dict或最终checkpoint。
5. 测试KL方向及温度缩放、全拒绝、零权重、教师无梯度、旧配置兼容、相同初始化与推理保存恢复。GPU检查不得干扰当前正在运行的F4；其结束后再做GPU预检。
6. GPU训练串行。失败时保留日志和已完成组；缺教师时依赖组明确失败／跳过，不用随机教师替代，不无限重试，不为正收益扩展参数搜索。
7. 所有标准报告用已有15×15混淆矩阵复核OA／AA／Kappa。报告不仅比较K组与F4，也与标签平滑C1比较；正负结果全部列出。
