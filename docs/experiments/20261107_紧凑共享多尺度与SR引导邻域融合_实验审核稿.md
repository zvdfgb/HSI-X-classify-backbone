## 1. 研究目标与实验定位

这套实验的核心验证目标不是“共享卷积核能不能涨点”，而是：**在紧凑多尺度跨模态融合底座上，引入正确的 `SR2` 邻域先验是否带来可区分、可解释的额外收益，以及融合阶段与读出阶段使用 `SR2` 的真实交互关系**。

与仓库历史实验及已有文献的边界：

| 对比对象 | 既有做法 | 本方案做法与结论边界 |
| --- | --- | --- |
| 仓库 `P01`（`20261103`） | `SR` 作为单模态 HSI 全局自注意力先验（`+0.05` pp） | `SR2` 进入 HSI–LiDAR 双模态跨通道空间卷积的邻域采样贡献调制 |
| 仓库 `HAMF`（`M04`，`20261105`） | 用 `SR` 调节不同尺度分支权重，且用 `groups=128` 深度卷积 | 保留全通道跨模态密集卷积，在每个尺度内部调节有效邻居的相对贡献 |
| 仓库 `BMAF`（`N04`，`20261106`） | 额外训练边界方差 MLP 门控调节分支 | 零新增门控参数，直接局部归一化复用前向已算出的 `SR2` 权重 |
| Kernel-Sharing Atrous Conv（2019） | 共享 `3×3` 核配多空洞率实现多尺度特征提取 | 已有相关研究，**仅作为控制多尺度参数成本的结构底座，不当作原创机制** |
| Pixel-Adaptive Conv（CVPR 2019） | 基于每个像素各自的局部特征成对距离调整卷积核 | 本方案使用的是**窗口各像素相对于窗口分类中心 `(5,5)` 的 `SR2` 先验权重**（不能描述成每个像素各自的邻域相似性），并专门检验其与末端 `SR2` 读出的四格交互 |

## 2. 精确算子定义、归一化公式与可核对伪代码

### 2.1 紧凑多尺度结构底座（`K01–K06` 共用可学习结构）
保持原生高光谱编码器（`3D Stem` + 固定 `1:1 LG`）、LiDAR 编码器、原生 `fusion_conv(128→64)` 与分类头不变。设两路编码特征拼接为 `X = cat[feat_hsi, feat_aux]`（形状 `[B, 128, 11, 11]`）：
1. **当前位置直连分支 `Y_0`（`44` 维）**：`Conv2d(128, 44, 1, bias=False) → BatchNorm2d(44) → ReLU → Dropout(0.1)`（参数 `5,720`）；
2. **跨模态通道压缩 `Z`（`42` 维）**：`Conv2d(128, 42, 1, bias=False) → BatchNorm2d(42) → ReLU`（参数 `5,460`）；
3. **共享跨通道卷积核 `W_shared`**：单一密集卷积核 `Conv2d(42, 42, 3, bias=False)`（形状 `[42, 42, 3, 3]`，`groups=1`，参数 `15,876`），分别以 `dilation = 1`（覆盖 `3×3`）和 `dilation = 2`（间隔采样覆盖 `5×5`）计算邻域卷积，后接各自独立的 `BatchNorm2d(42) → ReLU → Dropout(0.1)`（`bn_d1`、`bn_d2` 共 `168` 参数），输出 `Y_1`、`Y_2`；
4. **拼接回接**：`U = cat[Y_0, Y_1, Y_2]`（`[B, 128, 11, 11]`；仅 `K05` 取 `X + U`）送入原生 `fusion_conv(128→64)`、池化层（`SR2` 或均匀 `GAP`）与分类头。

### 2.2 融合阶段 `SR2` 邻域调制的精确公式与边界填充处理
1. **先验权重来源与物理含义**：
   在 `NeighborTransMixer.forward` 入口已无梯度算出 `W_sr = neighbor_weights(hsi_pca, aux)`（形状 `[B, 1, 11, 11]`，全窗非负且全窗和为 `1`）。**注意：`W_sr(q)` 度量的是窗口位置 `q` 相对于窗口待分类中心 `(5, 5)` 的空间—光谱一致性权重，而非每个输出位置 `p` 相对于其自身特征的局部相似性。**
2. **调制乘入位置**：
   权重**乘在进入跨通道卷积之前的每个邻居采样贡献上**（即对展开后的邻域特征张量逐采样点加权，再左乘共享跨通道核 `W_shared`），而非乘在卷积输出特征上。
3. **边界填充与有效邻居局部均值 `1` 归一化公式**：
   对任意空洞率 `d ∈ {1, 2}`，特征 `Z` 与先验图 `W` 统一采用与标准卷积完全一致的**零填充**（`padding = d, dilation = d`）。令全 `1` 张量 `1_{1×1×11×11}` 经相同零填充展开得到窗口内有效邻居指示掩码：
   - `M_d(p, t) ∈ {0, 1}`（`p ∈ {0..120}` 为输出像素位置，`t ∈ {0..8}` 为 `3×3` 采样位；当邻居 `q_t = p + d * delta_t` 落在 `11×11` 窗口内时 `M_d(p, t) = 1`，落在窗口外零填充区时 `M_d(p, t) = 0`）；
   - 位置 `p` 的窗口内有效邻居个数为 `N_d(p) = sum_{t=0..8} M_d(p, t)`（内部为 `9`，边缘为 `6`，角点为 `4`）；
   - 对任意非负空间先验 `W`（正确 `W_sr`、错位 `W_perm` 或均匀 `W_uni`），在 `float64` 精度下计算局部有效邻居归一化调制权重（保留 `float32` 正常数域 `> 1e-37` 内的全部相对权重比例，避免 `1e-12` 过早截断将边缘小权重 `1e-32..1e-13` 误归零；仅当某局部邻域全部采样位在 `float32` `softmax` 中下溢至 `<= 1e-37` 时退化为有效邻居均匀 `1.0`）：
     `S_d(p) = sum_{t'=0..8} M_d(p, t') * W(q_{t'})`
     `alpha_d(p, t) = M_d(p, t) * N_d(p) * W(q_t) / S_d(p)`（当 `S_d(p) > 1e-37`），否则 `alpha_d(p, t) = M_d(p, t)`
   - 跨通道邻域卷积输出：
     `ConvOut_d(b, c_out, p) = sum_{c_in=0..41} sum_{t=0..8} W_shared[c_out, c_in, t] * ( alpha_d(b, p, t) * Z_pad(b, c_in, q_t) )`
4. **尺度一致性与退化验证**：
   - 在每个输出位置 `p` 上，窗口外零填充采样位 `alpha_d(p, t) = 0` 且 `Z_pad(q_t) = 0`；在全部 `N_d(p)` 个窗口内有效邻居上，**局部调制权重的平均值恒等于 `1.0`**（`(1 / N_d(p)) * sum_{有效 t} alpha_d(p, t) = 1.0`），彻底避免直接使用全窗和为 `1` 的 `W_sr` 或由 `1e-12` 分母截断导致信号幅度改变；
   - 当 `W` 取均匀先验 `1/121` 时，所有有效邻居 `alpha_d(p, t) ≡ 1.0`，通过与 `SR2` 组完全一致的 `unfold + matmul` 算子路径执行，消除 cuDNN/cuBLAS 算子核差异，并在双精度下精确等价于标准零填充 `F.conv2d(Z, W_shared, padding=d, dilation=d)`。

### 2.3 可逐行核对的 PyTorch 伪代码

```python
def local_mean_one_tap_weights(w_map, dilation, in_bounds_mask):
    # w_map: [B, 1, 11, 11]（相对于窗口分类中心 (5,5) 的 SR2 权重、均匀 1/121 或仅融合错位副本）
    # in_bounds_mask: 预计算的 F.unfold(ones(1,1,11,11), kernel_size=3, dilation=d, padding=d)，形状 [1, 9, 121]
    w64 = w_map.to(torch.float64)
    m64 = in_bounds_mask.to(torch.float64)
    n_valid = m64.sum(dim=1, keepdim=True)  # [1, 1, 121]，取值为 4 / 6 / 9
    w_unf = F.unfold(w64, kernel_size=3, dilation=dilation, padding=dilation)  # [B, 9, 121]，窗口外填充为 0
    w_valid = w_unf * m64
    denom = w_valid.sum(dim=1, keepdim=True)  # [B, 1, 121]
    alpha64 = torch.where(denom > 1e-37, m64 * n_valid * w_valid / denom.clamp_min(1e-300), m64)
    return alpha64.to(dtype=w_map.dtype).unsqueeze(1)  # [B, 1, 9, 121]，有效邻居上均值恒为 1.0

def shared_atrous_sr_branch(z, weight_3x3, bn, dilation, in_bounds_mask, w_fusion):
    # K01..K06 统一走同一 unfold + matmul 路径（K01/K06 传入 w_fusion = 1/121，无算子后端混杂）
    b, c, h, w = z.shape
    alpha = local_mean_one_tap_weights(w_fusion, dilation, in_bounds_mask)  # [B, 1, 9, 121]
    z_unf = F.unfold(z, kernel_size=3, dilation=dilation, padding=dilation).view(b, c, 9, h * w)
    z_mod = (z_unf * alpha).view(b, c * 9, h * w)  # 乘在进入跨通道卷积前的每个邻居贡献上
    conv_out = (weight_3x3.view(c, c * 9) @ z_mod).view(b, c, h, w)
    return F.dropout(F.relu(bn(conv_out), inplace=True), p=0.1, training=bn.training)
```

### 3.1 “融合阶段 `SR` × 读出阶段 `SR`”完整四格对照逻辑（`K06 / K01 / K04 / K02`）

- **`K02 - K01`**：已经有末端 `SR2` 时，融合阶段再用 `SR2` 是否有额外收益？
- **`K04 - K06`**：没有末端 `SR2` 时，融合阶段单独使用 `SR2` 是否有收益？
- **`K01 - K06`**：在紧凑多尺度结构上，末端 `SR2` 读出本身的收益是多少？
- **交互项 `(K02 - K01) - (K04 - K06)`**：比较两个差值，判断两处同时使用 `SR2` 是互相帮助还是作用重复。**口径约束：该交互项仅用于描述当前设置下的协同或重叠现象，不直接称为统计显著或因果证明。**

### 3.2 四条硬性实现与结论收紧约束
1. **`K01 vs K00` 结论收紧**：`K00`（`92/18/18` 独立密集卷积）与 `K01`（`44/42/42` 共享核 + 不同空洞率）同时改变了分支通道分配、卷积核共享与较大范围采样方式。若 `K01` 优于 `K00`，**只能结论为“在接近的参数预算下，`K01` 这套紧凑多尺度结构整体优于 `K00` 这套结构”**，绝不单独宣称“证明了核共享有效”。
2. **`K03` 错位对照五项硬约束**：
   - `K01–K06` 可学习模块使用完全一致的初始化种子偏移，初始权重逐位相同；
   - **只打乱送入融合模块的 `SR2` 空间位置权重**；
   - **末端 `SR2` 读出仍使用未打乱的正确权重**（在 `forward` 中先拷贝 `w_sr.detach()` 做融合置换，保持 `self.gap.weights` 原值不变）；
   - 置换由独立私有 CPU 生成器（`seed = 20261107`）离线生成并注册为非训练 `buffer`，**完全不消耗训练随机数**；
   - 已验证 `121` 个位置存在 **`0` 个不动点**（`perm[i] != i` 对全部 `121` 个位置成立），完整 `121` 维置换序列同步记录于待审/批准矩阵 JSON 与运行报告中。
3. **证伪判据范围限定**：若 `K02` 不能同时优于 `K01` 和 `K03`，则**放弃本次固定设置（将相对于窗口中心的 `SR2` 权重经有效邻域均值 `1` 归一化用于共享空洞卷积调制）下的机制解释**，不靠重命名包装创新，也不据此泛化否定所有形式的 `SR` 引导融合。
4. **`K05` 结论边界与预设观察指标**：`K05 = K02 + 原始拼接特征残差` 仅检验加入直接保留原始两模态拼接特征的路径是否改善分类；即便提升，也不能单独证明此前是“原始信息被丢失”（残差同时改变输出幅度与优化过程）。所有组预先固定观察 **`seed6 / 7 / 8` 全部三个种子的 `OA`、`AA`、`Kappa` 以及 `Highway`、`Road`、`Commercial`、`Stressed grass` 等类别的召回率与 `F1`**，仅将历史 `seed6` 的 `Highway` 下降作为前期诊断线索。
