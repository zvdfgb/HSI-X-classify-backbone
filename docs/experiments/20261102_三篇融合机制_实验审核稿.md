# 三篇论文融合机制迁移：实验审核稿

日期：2026-11-02。状态：待用户审核；本次只形成方案，未修改模型、运行配置或训练源码，未启动实验。

## 1. 目标与边界

在现有A（局部/全局固定1:1通道分工 + SR2）上分别加入MFDNet、UMFNet、FINE的融合机制，判断收益是否来自具体机制，而不仅是增加参数或辅助监督。三套方向独立，不先叠加，不恢复旧PN、OC或蒸馏方向。

首轮共13项结果：复用A基线1项，新训12项；每个方向4组，新训均seed6、100轮，共1200个训练轮次。seed7/8、额外数据集、额外调参、联合模型均不在本次范围。旧B1的多种子授权不自动延伸到本批次。

这些是跨任务的机制迁移验证，不是三篇完整系统复现，也不是已经成立的原创贡献。论文原任务指标不与本项目OA比较。

## 4. 方向F：按频带融合并补偿细节

依据：[MFDNet，CVPR2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Zuo_Multi-modal_Frequency_Decomposition_Network_for_Semantic_Scene_Completion_CVPR_2026_paper.pdf)。核心是MAFF由整体特征预测频带融合权重，以及FDC用粗融合特征指导浅层高频补偿。作者原任务为RGB-D三维语义补全，本项目仅适配二维融合机制，不加入体素、占据或分割监督。

| 组别 | 加在A上的模块 | 要回答的问题 |
|---|---|---|
| F01 | 普通全频加权融合 + 全频浅层补偿 | 增加普通融合容量能带来多少收益？ |
| F02 | 三频带自适应融合，无浅层补偿 | 仅频带融合是否有用？ |
| F03 | 三频带自适应融合 + 全频浅层补偿 | 在同样补偿结构下，分频是否优于普通全频融合？ |
| F04 | 三频带自适应融合 + 高频浅层补偿 | 高频选择能否优于直接补充全部浅层信息？ |

拟固定实现：沿空间H/W做rfft2/irfft2，norm=ortho，逆变换显式使用原11×11尺寸；不是沿HSI光谱轴分频。依据实际离散频率半径归一化至[0,1]，用1/3和2/3为固定阈值，三张互斥掩膜覆盖全部频点；实施前检查奇数尺寸的每个频带非空。权重头从两模态全频特征的频谱幅值统计生成每模态/频带/通道权重，softmax在模态维归一化；各频带重构后形成两路残差更新，送入原fusion_conv。

F01使用相同数量的权重头及通道投影，对全频特征做普通加权混合；没有分频掩膜。保留相同的可训练投影分支，避免通过添加未使用参数伪造容量匹配。F01/F03/F04的新增有效参数拟保持相同，实施后报告实测；无法匹配时明确误差，不据此作严格单因素归因。

补偿输入为hsi_proj输出的浅层二维特征与aux_stem输出；输出由粗融合特征预测补偿权重，再残差加到fusion_conv之后、SR之前。注意现有LiDAR支路只有aux_stem，没有独立深层堆栈，因此不虚构LiDAR多尺度金字塔。F03取全频，F04用半径大于2/3的高频；其余补偿投影、权重头和初始化相同。11×11分频分辨率有限，频带数量和阈值本轮固定，不依据测试成绩搜索。

关键比较：F04−A00为总效果；F03−F01检验该分频方案；F04−F03检验高频选择；F04−F02检验整个细节补偿包，最后一项同时增加了分支容量，不能单独归因为高频。

损失：F01–F04均仅原CE。

## 5. 方向U：依据可靠性控制跨模态注入

依据：[UMFNet，CVPR2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Wang_Uncertainty-Aware_Modality_Fusion_for_Unaligned_RGB-T_Salient_Object_Detection_CVPR_2026_paper.pdf)与[官方代码](https://github.com/lfvision/Unaligned-RGB-T-Salient-Object-Detection)。核心是高斯潜变量UAM和由不确定性产生置信图的CGM。原显著性与边界监督不迁入分类任务，保留概率正则和可靠性调制。

| 组别 | 加在A上的模块 | 要回答的问题 |
|---|---|---|
| U01 | 确定性表示 + 普通内容门控 | 普通门控/加层能否达到同样效果？ |
| U02 | 概率UAM + KL + 通道/空间调制，置信系数固定为1 | 概率表示与普通调制本身是否有用？ |
| U03 | 概率UAM + KL + 空间可靠性CGM | 可靠性是否能有效控制信息注入？ |
| U04 | 与U03相同，但置信图先取空间均值后广播 | 是否需要逐位置的可靠性，而不仅是样本整体权重？ |

固定HSI为参考、LiDAR为引导，不再尝试反向并择优。两路原64通道特征经32通道潜变量均值/方差头与条件融合，再投影回64通道；参考支路接收残差更新，另一原支路保留进入fusion_conv。CGM保留通道缩放/偏置及空间调制。训练重参数采样，评估只取均值，不做多次采样集成。logvar按官方实现限制在[-10,10]，记录数值健康状况。

U01保留同规格双头和投影，两头均参与确定性内容表示与门控，不把未参与预测的参数算成有效容量。U02/U03/U04具有相同主干和概率头；U02将置信图替换为常数，移除其不生效的专属置信头并如实报告参数差异。U03/U04的同一置信头均实际参与反向传播，参数相同，差别仅在空间平均。

U02–U04：L = CE + 0.001 × KL。KL按batch、空间和潜变量维取均值，再对模态取均值；U01仅CE。0.001是本项目待审核的固定迁移系数，并非已验证最优值，不以测试OA调参。

关键比较：U03−A00为总效果；U03−U01为概率可靠性整包对普通门控；U03−U02检验置信调制；U03−U04检验空间局部性。U03−U01同时涉及采样、KL与表示差异，不能单独归因于置信图。现有配准误差和置信校准均未验证，不据此宣称已解决错位或估计得到真实概率。

## 6. 方向D：共享/特有分解与任务相关信息保留

依据：[FINE，AAAI2026](https://ojs.aaai.org/index.php/AAAI/article/view/37176)、[方法全文](https://arxiv.org/html/2511.20167v1)和[官方代码](https://github.com/Soceremite/FINE)。仅迁移FTRE的共享/特有分解与任务相关约束，不搬入专家Q-Former、对比队列或整套情感预测网络。

| 组别 | 加在A上的模块/目标 | 要回答的问题 |
|---|---|---|
| D01 | 同规格的共享/特有双投影与任务精炼，仅主CE | 单纯增加分支容量是否有用？ |
| D02 | D01 + 特征重建 + 分支辅助分类 | 普通辅助监督能否带来同样收益？ |
| D03 | D02 + 共享/特有分解互信息约束 | 有约束的分解是否优于仅增加辅助损失？ |
| D04 | D03 + 标签条件的任务相关互信息约束 | 剔除任务无关信息是否进一步有效？ |

每个模态64通道分别投影为32共享+32特有通道，四支均使用相同32→32任务精炼层。每模态拼回64通道形成残差更新，保留原fusion_conv与SR2。D01中的分支命名只是结构角色，不能据此宣称已经学到共享/特有语义。

重建目标为原两路特征（目标detach），MSE按所有元素取均值；用于重建的两支拼为64通道。辅助分类对四支按原SR2输入权重池化后接15类线性头，CE取四支平均。不把一个中心像素的类别伪造为整块像素标签。

D03的分解项：共享表示之间的InfoNCE下界最大化，以及跨模态特有表示之间的CLUB式上界最小化；D04另加入共享表示给定类别后的冗余抑制，以及特有表示与类别的相关信息保留。类别使用15类独热/32维类别嵌入，不以类别编号间距离表示语义。正负样本仅来自当前训练batch，不引入队列或更换采样器。条件估计中不足两个样本的类别不参与该项，无有效类则该项为0并记录有效样本数。

固定建议权重（均为本项目迁移设定，待审核）：

```text
D01: CE
D02: CE + 0.10·辅助CE + 0.01·重建MSE
D03: D02目标 + 0.01·分解MI + 0.01·相应critic拟合损失
D04: D03目标 + 0.01·任务MI + 0.01·新增critic拟合损失
```

各MI子项/critic项先按有效样本取均值，再按项数平均，避免因数量变化暗中改变损失尺度。InfoNCE温度固定0.1；不通过测试成绩调整温度或系数。

**与官方优化方式的差异必须披露：** 官方FTRE使用内部Adam优化器和交替critic训练。本项目保持原单AdamW、一次backward/step：表示目标使用detach后的critic权重，使梯度只更新表示；critic拟合使用detach后的特征/类别嵌入，使梯度只更新估计器。禁止直接让critic与表示共同最小化同一互信息上界，也不在adapter内部调用optimizer.step。该同步梯度隔离是适配方案，不等价于官方交替优化；若实现无法正确隔离则停止说明接口问题，不另写训练器。

关键比较：D04−A00为总效果；D04−D02判断是否超出普通辅助监督；D03−D02检验分解约束；D04−D03检验任务相关约束。训练专用critic和辅助头不计入推理参数，但须单独报告其训练参数和耗时。

## 7. 预先固定的判读方法

1. 主候选为F04、U03、D04，分别对A00计算OA/AA/Kappa差值（百分点）；同时报告全部对照，不只展示最好的候选。
2. 高于A仅说明该组合在seed6有提升线索；还必须比较对应容量/损失对照，才可讨论具体机制。优于A但不优于对照，结论应是容量或正则收益无法排除。
3. 用OA提升至少0.2个百分点、AA及Kappa均不下降作为优先进入后续审核的实用筛选线，不作为统计显著性阈值。0.2个百分点约相当于12197个测试点中多正确25个；低于此线仍完整报告。
4. 并列报告15类召回/F1及混淆矩阵，检查少数类损失与相近地物混淆。指标统一由原evaluator/metrics产生；不另写替代指标函数。
5. 若完整方案不如对应对照，可得出“本接入位置与固定设置下不支持继续复杂化”的结论；不能据一组seed6断言论文方法普遍无效。若仅部分组件有效，后续先审核保留简化版本，不自动扩展实验。
6. 三个方向不预定必须产生一个赢家；单种子、单数据集及测试OA参与选模限制必须保留，不声称稳定性、独立泛化收益或统计显著。
