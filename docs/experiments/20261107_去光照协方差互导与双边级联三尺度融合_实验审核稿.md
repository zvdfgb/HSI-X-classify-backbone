逐样本混淆与检查点张量核查定位出四个核心症结：

1. **缺失 `cat[H, L]` 像素级恒等残差直通，导致 `seed6` 单一类别 `Highway` 占总掉分的 `88.8%` 且 `Road` 三种全负**
   - `C02` 在 `seed6` 相比 `A0` 净丢 `502` 个测试样本，其中仅 `Highway` 一类就丢了 `446` 个（召回率从 `99.42%` 跌至 `56.47%`），`Road` 三种均值下滑 `-3.31` pp；`N02` 同样完全覆盖 `X_raw = cat[H, L]`，其 `fusion_conv` 分配给 `5×5` 分支的权重范数比 `1×1` 高出 `+53%`（`2.83` vs `2.29`），大感受野在空间聚集训练块上记忆背景捷径。
   - 保留 `cat[H, L]` 直接残差的模型（`I01`、`G03`）在 `seed6` 上 `Highway` 均维持 `99%+`；`HAMF` 失效是因为 `0.1` 标量门控在 `AdamW(lr=1e-4)` 下步长受限且 `groups=128` 割裂跨模态空间耦合。
2. **原版 `CF-IPT` 互导存在 `93%` 窗口亮度直流偏置（DC Bias）及对 LiDAR 边缘的空间模糊**
   - 检查点实测 `C02` 通道互导 `H_flat @ L_key_flat^T` 中窗口均值直流项 `|DC| = 8.56~17.20`，远大于空间共变交流项 `|AC| = 0.56~1.38`，在 `Houston2013` 东侧云影区（`Highway` 测试集 `42%` 处于阴影区，HSI 亮度从 `+0.169` 降至 `-0.957`）引发通道注意力路由漂移；同时 `vl @ spatial`（熵 `4.30~4.36`，混入约 `78/121` 个像素）模糊了 LiDAR 锐利高程阶跃。
3. **平铺 `5×5` 卷积参数冗余**：`C02` 单层 `128×128×5×5` 占 `409,728` 参数（整网 `60.2%`），三尺度孤立并联、无跨尺度递进复用。
4. **可学习动态门控在小样本上易过拟合**：`C04 < C02`、`M04 < M01`、`N04 < N02` 三批次一致复现动态门控负收益。

## 2. 四个候选创新调整方向（方向 1–4）

```text
H [B,64,11,11] ──┬────────────────── X_raw = cat[H, L] ──────────────────┐
                 ├─► (方向2: ISC 去光照协方差与保边非对称互导) ─► [H', L']  │
L [B,64,11,11] ──┘                        │                              │
                                          ▼                              │
                        Conv1x1(128→128)+BN+ReLU → 切分 (44, 42, 42)      │
                          ├─ Z_1 (44维) ──────────────────────► Y_1      │
                          ├─ Z_3 (42维) ─► 3×3 (+方向4 MBP) ──► Y_3      │
                          └─ Z_5 (42维) + Y_3 ─► 3×3 (+MBP) ─► Y_5      │
                                      (方向3: HCP 渐进级联三尺度)          │
                                          │                              ▼
                             Dropout(0.1) + Conv1x1_out(128→128) ──► (+) IRH 残差
                                                                         │
                                                                         ▼
                                                原 fusion_conv(128→64) ─► 原 SR2 ─► 原分类头
```

1. **方向 1（`IRH`）：保边恒等残差直通与无标量扼流跨尺度投射**
   - 采用 `X_out = cat[H, L] + Conv1x1_out(U_ms)`（无偏置 `128→128` 线性投射，取消 `0.1` 标量衰减）。标准初始化下第 `0` 步天然保持 `||Delta_X||_rms / ||X_raw||_rms ≈ 0.20`，保住 `A0` 像素对齐底盘同时具备矩阵级快速自适应能力。
2. **方向 2（`ISC`）：去光照偏置结构协方差与保边非对称互导（`24,706` 参数，比 `CF-IPT` 少 `126` 参数）**
   - `L → H` 通道校准：窗口去均值 + `L2` 归一化余弦结构协方差 `softmax((H_hat @ L_hat^T) / tau_ch)`，对任意线性阴影变换 `a * H + b` 严格不变；
   - `L, H → H` 空间引导：`32` 维归一化交叉亲和度聚合高程同质邻域；
   - `H → L` 保边门控：用 `1×1` 点对点语义门控 `Sigmoid(BN(W_g(H))) * W_v(L)` 替代 `vl @ spatial`，零空间模糊保留 LiDAR 屋檐与路缘。
3. **方向 3（`HCP`）：跨模态共享子空间与渐进级联 `3×3 → 3×3` 三尺度金字塔**
   - 共享 `128→128` 投射后切分 `(44, 42, 42)`，以级联 `Y_3 = B_3(Z_3)`、`Y_5 = B_5(Z_5 + Y_3)` 替代平铺 `5×5`，形成中心峰值等效感受野并实现跨尺度特征复用，`5×5` 核参数较 `C02` 减少 `96.1%`，整网参数降至 `170,537`（较 `C02` 减少 `74.9%`）。
4. **方向 4（`MBP`）：与 `SR2` 同源的无参数多模态双边亲和度卷积（`+0` 参数）**
   - 在 `3×3` `unfold` 邻域内乘上输入 `(hsi_pca, aux)` 局部方差归一化的光谱+高程双边亲和权重（中心恒为 `1.0`、`9` 点均值归一化），在池化前阻断跨路缘/屋顶异质污染且无门控过拟合风险。
