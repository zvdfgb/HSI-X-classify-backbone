# SR与固定1∶1局部／全局分工：证据、重构与待审核训练

日期：2026-11-04。状态：候选代码和CPU合成输入预检完成；12项新训练尚未批准或启动。当前有另一个已批准批次运行，因此本次不修改其封存的模型注册表。

## 先回答“SR配合全局可以提升吗”

**目前可以说SR值得保留，全局交互也有价值；还不能说已经证明SR特别适合全局。** 原因是已有LL／GG算子对照都加了SR，缺少“双全局不加SR”这一格。看到“双全局＋SR成绩不错”，并不能知道其中多少提升来自SR。

已有结果采用原生报告，全部为Houston2013的seed6／7／8；±为三个种子的样本标准差，不是置信区间。

| 结构 | 平均OA（%） | 从结果能读出什么 |
|---|---:|---|
| 纯SSM | 87.0624 ± 0.5493 | 原项目参照 |
| 纯SSM＋SR | 88.1528 ± 0.8466 | SR平均提高1.0904个百分点，3/3种子为正 |
| 固定局部／全局，不加SR | 87.0351 ± 2.8056 | 分工单独平均收益接近零，种子波动大 |
| 固定局部／全局＋SR（LG） | 89.3990 ± 2.6142 | 比仅分工高2.3640个百分点，2/3种子为正 |
| 双局部＋SR（LL） | 87.5243 ± 1.8216 | LG高1.8748个百分点，3/3种子为正 |
| 双全局＋SR（GG） | 89.4100 ± 1.2734 | 与LG平均几乎持平；LG只有1/3种子胜过GG |

这里“纯SSM”仍包含卷积输入层、LiDAR支路、融合层与分类头；SSM本身也处理窗口内的上下文。GG也保留这些结构，只将分工块中的两个算子都设为注意力。不能把这几组称为完全没有局部／全局信息的网络。

LG相对GG三个种子的OA变化分别为+4.1650、−3.0827、−1.1150个百分点，均值−0.0109。平均相等掩盖了明显的种子差异。GG的样本标准差更小只是这次三种子的观察，不能宣称统计上更稳定。

## 为什么仍值得保留局部分支

**整体OA相同，不等于识别的对象相同。** 道路类有1059个测试样本：LG相对LL的召回率平均高9.8521个百分点，相对GG高6.4526个百分点，两个比较都是3/3种子同向。GG在其他类别追回了分数，例如高速公路平均比LG高2.8636个百分点，因此整体抵消。

再看旧四格：分工单独使道路召回率相对纯SSM下降11.1426个百分点；在分工上加SR后，道路召回率提高11.3944个百分点。这给出一个具体线索：SR和混合算子可能在道路这类对象上有配合价值。它尚不能证明是SR造成了LG相对GG的优势，因为LL／GG这次都使用SR；也不能泛化为所有细长目标或所有边界。

SR可以通俗理解为“最后汇报时，哪些邻居的话更值得听”。局部卷积处理附近的形状和变化，注意力建立11×11窗口内较远位置之间的关系。原流程先产生这些特征，再由SR按距离和输入光谱相似性汇总位置。SR没有可训练参数，也不读取标签。

已完成的权重诊断支持“SR在筛选邻居”：在854个已知标签覆盖足够的混合邻域中，已知异类邻居的平均权重质量从均匀汇总的14.41%降到约0.75%。但分工上加SR在这些混合邻域中的平均OA变化仍为−1.913个百分点，主要受seed6的受胁草地影响；跑道混合邻域每个种子都净少判对6个。筛选权重合理和实际分类更好是两回事。

因此本次目标是保住局部有价值的信息，再提高两路配合效率，而不是由平均成绩持平就删除局部。

## 原混合块有哪些可检查的改进空间

原代码每个块先过SSM，再把64通道固定分成32＋32。全局支路输出包含“原输入＋注意力更新”；局部支路直接使用卷积输出，没有同位置的局部输入残差。两路算子及归一化也不同，拼接时更新尺度可能不一致。

这不是已证实的代码错误，也不是已证明的性能根因。它提示一个可验证假设：局部有用信号可能在更新中保留不足；不同样本需要的局部／全局更新强度也可能不同。最后一次SR汇总无法保证恢复此前已经丢失的信息，因此可以尝试让SR同时参与更新强度的选择。

已有B1试过局部残差，不能把“加一条残差”重新称为新创新。P01也试过保留末端SR、额外给注意力加入SR先验，平均仅高0.0547个百分点，相对错位先验高0.0519。本次不重复该做法，也不能由P01概括“SR放在融合前后没有区别”。

## 已实现的候选：让SR帮助决定两路各更新多少

代码：[独立模型](../../src/models/transmixer_sr_lg_v2/model.py)、[标准adapter](../../src/models/transmixer_sr_lg_v2/adapter.py)。原模型类、训练器与历史checkpoint均保留。

数据依次经过：

```text
原HSI输入层 → 原SSM → 固定32／32通道
  全局32：原注意力 → 更新归一化 → 原输入＋全局增益×更新
  局部32：输入归一化 → 原局部卷积 → 更新归一化 → 原输入＋局部增益×更新
          两路更新 → 用SR汇总成一个摘要 → 小网络产生两个增益
→ 原拼接投影和外层残差 → 第二个同类块
→ 原HSI／LiDAR融合 → 原正确SR汇总 → 原分类头
```

具体改变三件事：

1. **两路都保留原信息。** 局部支路也采用“原输入＋更新”，减少只剩新卷积结果的风险。
2. **先校准更新尺度。** 对两路更新分别做LayerNorm，让增益控制更新强度时有更可比的输入；局部卷积前也加入LayerNorm。是否有益仍需训练。
3. **每个样本、每个块产生两个增益。** SR先加权汇总两路更新，再由小网络输出全局、局部各一个标量。取值为`2×sigmoid`，范围0到2，初始均为1；允许一条路少更新或多更新。两个增益不要求相加为1，也不改变32／32的固定通道数量。

例如，道路样本可能需要更多局部更新，大面积同类区域可能需要更多全局更新。这只是设计意图，当前还没有训练后的增益统计，不能提前说模型已经学会这种分工。SR与真实语义类别也并非完全对应，输入光谱相似性可能失效。

SR权重仍完全复用原公式，只用输入计算一次。末端SR始终保持正确对齐。候选参数83,419，原LG＋SR为80,887，增加2,532（约3.13%）；三个新混合版本容量相同。GG为86,583，因而候选与旧GG／LG的比较仍不是完全等参数比较。

## 怎样分清改善来自哪里：12项待审核矩阵

每组seed6、7、8各一次，共12项新训练。复用M0、M2、M3和GG＋SR各三个历史结果，共12项参照，不重训。

| 组别 | 结构变化 | 中间摘要 | 最后汇总 | 新训练数 | 回答的问题 |
|---|---|---|---|---:|---|
| R00 | 原GG，其他不变 | 无新模块 | 原平均汇总，不加SR | 3 | 对比旧GG＋SR：SR在GG上到底提高多少 |
| R01 | 对称残差、更新校准、两个增益 | 所有位置平均 | 正确SR | 3 | 重构整体是否有帮助 |
| R02 | 与R01完全相同 | 正确SR加权 | 正确SR | 3 | 候选：SR条件摘要是否优于普通摘要 |
| R03 | 与R02完全相同 | SR权重固定错位37格 | 正确SR | 3 | 摘要中正确的位置对应是否有价值 |

全部沿用Houston2013官方划分、PCA30、11×11、100轮、batch128、AdamW学习率1e-4、weight_decay0.01及原SR参数，不增加损失、调参搜索或额外种子。统一调用`scripts/train.py → src/runner.py → src/trainer.py`，使用原数据／指标／评估实现。

比较顺序预先固定：

1. 旧GG＋SR减R00，得到SR在GG上的增益；与旧M2减M0比较，描述SR在两类骨干上的收益是否不同。不同骨干还包含容量、初始化路径等差异，不能当作纯粹因果证明。
2. R02对R01：同等容量、相同初值、相同末端SR，只改变中间摘要的加权方式。
3. R02对R03：检验这一个固定错位对照；不代表所有可能的错位。
4. R02对旧LG＋SR和GG＋SR：整体精度是否真正提高，道路收益是否保留，有没有以其他类别退化换取局部提升。

每项报告OA、AA、Kappa、全部类别召回率、同种子差值和三种子样本标准差。重点核对道路、受胁草地、跑道和高速公路，但不能只挑有利类别。训练后另做只读全测试集增益统计，检查不同样本是否真的产生不同增益；`diagnostics()`当前只保存最后一批的增益，不能拿它冒充全测试集统计。

如果R02不优于R01，不能说SR引导是有效创新；如果不优于R03，正确对齐的机制证据不足；如果只在一个种子提高，不能称为稳定改进。若OA提高却道路下降，应如实报告取舍。R01把残差、校准、普通摘要门控作为整体改变，不能从它拆出三项的独立贡献。三种子和单数据集的结果也不构成显著性或泛化证明。

原训练器仍按测试OA保存模型，本次保持该规则；所有成绩只能作为这一选模协议下的探索性结果，不能称为独立测试。
