## 1. 上一轮 `HAMF`（`M00–M05`）的实证复盘与精确根因

在 `fusion_hamf_seed678_20261105`（18 项新训）中，`M00–M05` 三种子平均 OA 为 `88.65%–89.17%`，未能超过 `A0`（`89.3990%`）或复现 `C02`（`90.8256%`）。结合步级诊断日志、逐类召回率与 Houston2013 实测邻域统计，已定位全部三个失效根因及 `C02` 涨点的真实来源：

1. **根因一：`0.1` 残差标量在 `AdamW lr=1e-4`（`2,200` 步）下触及步长上限，造成 83% 恒等捷径旁路**
   - `M01–M05` 的 `alpha_h, alpha_l` 与外层 `gamma` 初值均设为 `0.1`。全部 18 次训练中它们均单调上升但受限于 `lr=1e-4 × 2200` 步物理上限，第 100 轮终值仅 `0.15–0.24`，导致跨模态到多尺度通路有效权重仅 `0.18 × 0.18 ≈ 3.2%`，第 10 轮 OA 仅 `70.0%`（而无 `0.1` 衰减的 `C01/C02` 第 10 轮达 `77.8% / 85.0%`）。
   - 同时对已保存 `C02` 权重的实测复查表明：原生 `CrossModalRelations`（无 `0.1` 衰减、无额外温度稀释）空间注意力熵为 `4.37–4.57`（理论上限 `ln(121)=4.80`）、通道注意力熵为 `1.03–1.12`，本身处于健康动态区间，无需 `0.1` 压制或温度平滑。
2. **根因二：`groups=128` 逐通道深度卷积割裂了“光谱 × 邻域高程”跨模态空间联合滤波**
   - `C02` 在 `concat[H', L']` 上做跨通道空间卷积，单个 `3×3 / 5×5` 核可同时耦合中心光谱与邻域 LiDAR 高程梯度（在云影覆盖区 `Stressed grass` 提升 `+3.63` pp、`Highway` 提升 `+6.18` pp）；而 `groups=128` 深度卷积仅在单一模态单通道内平滑，`M00–M05` 在 `Stressed grass` 上增益全部归零（`+0.00` pp）。
3. **根因三：全窗 `softmax` 权重反转与三分支强制均分损伤细窄地物**
   - 全窗归一化 `W_sr` 在细窄 `Road` 处因周围异质像素趋零而令中心 `121 * W_sr[5,5]` 反相激增，导致 `M04` 在 `Road` 中心给 `5×5` 分支分配了 `98.06%` 权重；此外 Houston2013（`2.5m` 分辨率）实测显示沥青 `Road` 与灰顶 `Commercial` 纯光谱邻域同质度几乎相同（`0.5416` vs `0.5414`），区分道路边界的关键物理信号必须同时包含 **LiDAR 局部高程跳变方差**。

## 2. 修正融合架构：边界感知跨模态密集多尺度融合（BMAF）

严格保留原网络编码主干、`fusion_conv(128→64)`、末端 `SR2` 池化与分类头不变，仅针对上述三个根因做最小精准修正：

```text
HSI 深层特征 H [B,64,11,11] ──┐
                              ├─► (1) 原 C02 无衰减非对称双向互导 ─► X = concat[H', L'] [B,128,11,11]
LiDAR 浅层特征 L [B,64,11,11] ─┘                  │
                                                  ├──► B_1: 1×1 跨模态锐利分支 [B, 44, 11, 11]（恒为 1.0 保边）
                                                  ├──► B_3: 1×1 瓶颈 + 密集 3×3 跨模态分支 [B, 42, 11, 11] × g_3
                                                  └──► B_5: 1×1 瓶颈 + 密集 5×5 跨模态分支 [B, 42, 11, 11] × g_5
                                                                        ▲
输入 (hsi_pca, aux) 局部 3×3/5×5 光谱+高程边界方差图 ──► (3) 有界调制 g_3, g_5 in (0.5, 1.5)（初值 1.0）
                                                                        │
                                             concat[B_1, g_3*B_3, g_5*B_5] [B, 128, 11, 11]
                                                                        │
                                                                        ▼
                                                原 fusion_conv(128→64) ─► 原 SR2 ─► 原分类头
```

### 2.1 子部件一：原位保留验证有效的无衰减非对称双向互导
- 直接采用 `C02` 已验证有效的双向跨模态互导（`H' = H + A_ch @ V_h`，`L' = L + V_l @ A_sp`，参数量 `24,832`），**彻底取消 `0.1` 标量衰减与额外温度缩放**，确保第 1 轮起跨模态校准信号即以单位尺度完整传播。

### 2.2 子部件二：分通道跨模态瓶颈密集多尺度金字塔（保留跨模态空间耦合、减重 73%+、解除强制均分）
令 `X = concat[H', L']`（`[B, 128, 11, 11]`），按通道容量拆分为 `(44, 42, 42)` 三条并行跨模态分支，拼接回 `128` 维（`44 + 42 + 42 = 128`）送入原生 `fusion_conv(128→64)`，**取消外层 `0.1` 恒等旁路，同时取消三尺度强制相加均分**：
- **`1×1` 保边锐利分支 `B_1`（`44` 维）**：`Conv2d(128, 44, 1) → ReLU → BatchNorm2d(44) → Dropout(0.1)`（单层直通，与 `C02` 的 `1×1` 分支深度、算子顺序完全一致，参数 `5,764`）。
- **`3×3` 跨模态局部密集分支 `B_3`（`42` 维）**：`Conv2d(128, 42, 1, bias=False) → BatchNorm2d(42) → ReLU → Conv2d(42, 42, 3, padding=1) → ReLU → BatchNorm2d(42) → Dropout(0.1)`（先将 64 维光谱与 64 维高程融合为紧凑 42 维，再做**全通道密集 `3×3` 空间卷积**，完整保留跨模态空间耦合，参数 `21,462`）。
- **`5×5` 跨模态上下文密集分支 `B_5`（`42` 维）**：`Conv2d(128, 42, 1, bias=False) → BatchNorm2d(42) → ReLU → Conv2d(42, 42, 5, padding=2) → ReLU → BatchNorm2d(42) → Dropout(0.1)`（紧凑 42 维上的**全通道密集 `5×5` 空间卷积**，参数 `49,686`）。
- **核心结构优势**：
  1. 三条分支总参数仅 **`76,912`**（较 `C02` 的 `574,592` **削减 `86.6%`**，整网参数从 `680,311` 降至 **`182,631`**，**减重 `73.2%`**）；
  2. `3×3` 与 `5×5` 均为真正的全通道跨模态密集卷积（各含 `1,764` 个跨模态空间核），不割裂光谱与邻域高程耦合；
  3. 三尺度按通道拼接 `[B_1, B_3, B_5]` 而非死板相加，使 `44` 维清晰 `1×1` 特征不会被 `5×5` 平均覆盖。

### 2.3 子部件三：多模态局部边界方差引导的有界尺度调制（无反转、不坍缩、保护 `1×1`）
只对大核分支 `B_3`、`B_5` 施加像素级有界调制 `g_3, g_5`，**`1×1` 分支 `B_1` 恒保持 `1.0` 不受抑制**：
- **无参数多模态局部边界能量图**（仅用输入 `hsi_pca` 与 `aux`，`detach` 无梯度、无标签泄漏）：
  采用边界复制填充 `replicate`（消除窗口边缘零填充伪影），计算每个像素 `(u, v)` 周围 `3×3` 与 `5×5` 邻域内的光谱局部方差 `v_h3, v_h5` 与 **LiDAR 高程局部方差 `v_l3, v_l5`**，并各自除以窗口均值做块内归一化（对云影整体变暗及绝对海拔高度完全不变），拼接为 `Bnd = concat[v_h3, v_l3, v_h5, v_l5]`（`[B, 4, 11, 11]`）。在道路路缘、建筑屋檐、立交桥边缘及树冠交界处，`v_l` 或 `v_h` 显著高于 `1`；在同质区内部显著低于 `1`，物理方向恒定不反转。
- **有界中心调制（杜绝 `softmax` 竞争坍缩）**：
  - 特征门控支路：`U = concat[B_1, B_3, B_5]` 经 `Conv1x1(128→16) → ReLU → Conv1x1(16→2)` 得 `logits_feat`（参数 `2,098`，末层零初始化）。
  - 边界先验支路：`Bnd` 经 `Conv3x3(4→8, padding=1) → ReLU → Conv1x1(8→2, bias=False)` 得 `logits_bnd`（参数 `312`，末层零初始化）。
  - 合成调制系数：`[g_3, g_5] = 1.0 + 0.5 * tanh(logits_feat + logits_bnd)`，取值严格有界于 **`(0.5, 1.5)`**，训练第 0 步精确满足 **`g_3 = g_5 = 1.0`**（既无 `0.1` 步长饥饿，又绝不会像 `softmax` 那样单尺度吞噬至 `0.98` 或通道坍缩至 `128`）。
