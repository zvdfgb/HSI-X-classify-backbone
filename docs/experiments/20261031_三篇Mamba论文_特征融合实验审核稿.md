## 1. 本轮命名与共同结构

- R：既有纯 SSM + 原 HSI/LiDAR 拼接融合 + 平均汇总，对应 `sr_native_20261029` 的 M0。
- A：既有局部／全局固定 1:1 通道分工 + 原 HSI/LiDAR 拼接融合 + SR2，对应该批次的 M3。
- B1：MMMamba 启发的对应位置交错扫描融合。
- B2：AMTrack 启发的跨模态条件状态融合。
- B3：SMC-Mamba 启发的动态多专家融合及共识约束。

本轮的 A 是原报告中两个模块的组合；不追溯修改原报告的 A/B 命名。严格按代码位置说，1:1 分工属于特征提取，SR2 属于最后的加权汇总。沿用用户的统一简称 A，不把 SR2 说成改动了前面的 SSM。

所有新候选都在两模态特征提取完成后、原 `fusion_conv` 之前介入：

```text
HSI → 原浅层提取 → 原 SSM / 固定 1:1 模块 → H ┐
                                                  ├→ 新融合交互 Bi
LiDAR → 原辅助模态浅层提取                  → L ┘
       → 原拼接 + fusion_conv → 原 SR2 → 原分类头
```

R+Bi 使用原纯 SSM 提取和平均汇总；A+Bi 使用原 1:1 提取和 SR2。Bi 的结构、宽度、初始化规则与超参数在两者之间固定。

H 和 L 均为 64 通道、11×11 特征图。新增交互返回同样大小的两张图，原拼接融合、汇总和分类头继续执行。A+Bi 中 A 也参与从头训练，**不冻结旧 A 的检查点，也不额外微调 100 轮**。

## 3. B1：对应位置交错扫描融合

### 研究问题

原融合主要在相同位置拼接两模态，缺少沿空间上下文的信息交换。让 HSI 和 LiDAR 对应位置在同一状态序列中紧邻，是否比独立处理或整段拼接更有效？

### 固定实现

将特征按行展平为 `h1...h121` 和 `l1...l121`。固定 64 维、状态维16；使用同一个新增 `SelectiveSSM2D` 的参数处理两模态及两个扫描方向。每次调用状态从零开始。两模态各有自己的 LayerNorm，三种对照完全相同。

显式调用正向与反向扫描，反向结果恢复原位置后取平均。**现有 `SelectiveSSM2D.forward` 实际只有正向递推，不能因为旧注释写了“双向”就认为已自动实现反向。** 本轮只增加融合层的反向调用，不改原提取器。

- 独立扫描：分别扫描 H、L，各自在模态边界重置状态，不能跨模态传递状态。
- 整段拼接：扫描 `[h1,...,h121,l1,...,l121]`，允许跨模态传递状态。
- 对应交错：扫描 `[h1,l1,h2,l2,...,h121,l121]`，对应位置相邻。

扫描结果拆回两模态，通过各自零初始化的可学习残差系数加回 H、L，然后进入原 `fusion_conv`。三种组别的可训练参数相同；两方向合计扫描位置数同为484，但序列长度、调用次数与状态边界不同，实际延迟需要测量。

本轮采用像素 token、行序及其反向，不复制原文四方向局部块扫描，不改变 SR2 权重或原提取器扫描顺序。

### 分组与判读

| 组别 | 设置 | 比较目的 |
|---|---|---|
| G02 | A + 两模态独立扫描 | 控制“多加一层 SSM”带来的变化 |
| G03 | A + 两模态整段拼接扫描 | G03−G02：允许跨模态状态传递是否有用 |
| G04 | A + 对应位置交错扫描，B1完整版 | G04−G03：对应交错是否优于整段拼接 |
| G05 | R + 与G04完全相同的 B1 | 检查 B1 脱离 A 的作用及与 A 的交互 |

G04 仅超过 A 而未超过 G03，最多支持“新增扫描融合有帮助”，不能据此宣称交错顺序有效。

## 4. B2：跨模态条件状态融合

### 研究问题

LiDAR 能否通过控制 HSI 的状态写入、读出和更新尺度，提供比普通相加或自身状态建模更有效的几何条件？反向用 HSI 条件控制 LiDAR 分支，组成完整融合。

### 固定实现

在融合位置新增两个目标模态各自的条件 SSM，宽度64、状态维16。两模态之间不共享参数，正反方向共享各目标层参数。每个方向均从零状态开始，输出恢复位置后平均，再以零初始化可学习残差系数加回目标特征。

SSM 中的状态矩阵记作 `A_ssm`，避免与本轮模型组合 A 混淆。保持原有指数衰减与 softplus 步长的数值形式；只切换 B、C、Δ 的输入来源，三组的参数数量和扫描方向相同：

- 自条件：数据、B、C、Δ 全部来自目标模态。
- 跨模态 B/C：数据和 Δ 来自目标模态，B、C 来自另一模态。
- 跨模态 B/C/Δ：数据来自目标模态，B、C、Δ 来自另一模态，对应 AMTrack Algorithm 1 的条件来源。

本轮保留原提取器；在新增融合层内实现条件参数投影和状态计算。它是模型层的递推，训练仍完全调用原训练器。现有 SSM 的 `forward(x)` 没有独立的条件输入，不能直接把两个输入拼在一起就声称实现了 MSSM。

### 分组与判读

| 组别 | 设置 | 比较目的 |
|---|---|---|
| G06 | A + 双模态各自自条件 SSM | 控制增加相同规模状态层的作用 |
| G07 | A + 跨模态 B/C，Δ仍为自条件 | G07−G06：跨模态写入／读出控制的作用 |
| G08 | A + 跨模态 B/C/Δ，B2完整版 | G08−G07：另一模态控制更新尺度的额外作用 |
| G09 | R + 与G08完全相同的 B2 | 检查 B2 脱离 A 的作用及与 A 的交互 |

G08 若未超过 G07，应保留“跨模态 Δ 无额外收益或产生负作用”的结果；不预设全面交互一定更好。跨模态条件仍可能受噪声影响，本轮不宣称鲁棒性已得到验证。

## 5. B3：动态多专家融合及共识约束

### 研究问题

不同窗口需要的光谱与几何信息可能不同。多个轻量融合专家按输入内容协作，能否比平均使用这些专家更好？增加均衡与共识约束后是否有额外价值？

### 固定实现

固定4个独立参数、相同结构的轻量专家。每个专家读取 `[H,L]` 的128通道拼接，使用 `1×1卷积128→16 → GELU → 1×1卷积16→128`，输出可拆回 H、L 的两模态残差。不引入 B1/B2 的扫描，便于单独检验专家融合。

门控读取 `[H,L]` 的 `GAP+GMP`，用 `128→16→4` MLP 和 softmax 得到每个窗口的4个权重。所有组都创建相同的专家和门控结构；均匀组固定用1/4权重，门控输出不参与损失，因此需同时报告总参数与实际参与学习的参数。

全程使用稠密 softmax，训练与推理都计算4个专家；不启用原文的随机噪声、Top-k稀疏执行、多样性损失或随轮次变化的调度，也不宣称节省推理计算。专家结构改为轻量卷积，属于 MCCM 思路的简化迁移，不称为完整 SMC-Mamba。

合成残差通过两个零初始化可学习系数加回 H、L，后接原 `fusion_conv`。专家不预先命名为“建筑专家”“植被专家”，这些分工需要额外证据。

固定辅助约束如下，均只在原训练批次计算：

```text
p_e = 当前批次中专家e的平均门控权重
L_bal = 4 × sum_e (p_e − 1/4)^2

u_e = E_e / sqrt(mean_channels(E_e^2) + 1e-6)
u_bar = sum_e π_e × u_e
L_cons = mean_batch,space(sum_e π_e × mean_channels((u_e − u_bar)^2))
```

共识作用于按位置、按通道 RMS 归一化后的专家残差，减少单纯输出尺度的影响；这与原文原始特征平方范数的形式有差别，应在报告中明确。梯度通过专家、门控及共识目标正常传播，不使用标签生成专家目标。

固定 `λ_bal=0.01`、`λ_cons=0.001`，不在本批次搜索权重。

### 分组与判读

| 组别 | 设置 | 训练损失 | 比较目的 |
|---|---|---|---|
| G10 | A + 4专家均匀融合 | CE | 控制多专家容量 |
| G11 | A + 4专家动态融合 | CE | G11−G10：按输入分配专家的作用 |
| G12 | A + 动态融合 + 均衡约束 | CE + 0.01 L_bal | G12−G11：均衡约束的作用 |
| G13 | A + 动态融合 + 均衡 + 共识，B3完整版 | CE + 0.01 L_bal + 0.001 L_cons | G13−G12：共识约束的额外作用 |
| G14 | R + 与G13完全相同的 B3 | 与G13相同 | 检查 B3 脱离 A 的作用及与 A 的交互 |

共识可能使专家趋同；本轮未加入原文多样性机制，必须记录专家权重、权重熵、输出RMS及两两相似度。若权重趋近固定、专家输出趋同或残差系数接近0，则不能把 OA 变化解释为有效的动态专门化。均衡约束也不能保证专家学出不同知识。

## 9. 结果怎样判定

### 总体指标

主指标 OA；同步报告 AA、Kappa、各类别召回率、混淆矩阵，以及总参数／参与学习参数、训练耗时、峰值显存和同设备推理延迟。所有精度从原 evaluator/metrics 的结果读取，新增汇总只做算术，不另写分类指标函数。

记录每个种子的实际结果、均值、样本标准差、与同seed基线的差值和正向种子数；保留所有负结果，不用seed6单次最好成绩代表整体。

既有A的三种子OA为92.4080%、87.6855%、88.1036%，均值89.3990%、标准差2.6142个百分点。它的波动是本轮必须解释的背景，不能预设A稳定有效。

### 三层结论分开

1. **组合是否值得继续**：分别看 G04/G08/G13 相对 G01。预先设一个继续研究的严格优先条件：平均OA至少提高0.5个百分点，且3/3种子都为正。只出现平均提升或2/3为正时，记录为混合证据，不直接宣称稳定提升；该门槛是资源优先级规则，不是显著性检验。
2. **声称的具体机制是否有支持**：还要看上述指定相邻对照。相邻机制对照平均改善且至少2/3种子为正，才给出初步支持；3/3更一致。某一机制未通过，只能保留较窄结论。例如G13不超过G12，就不能说共识约束有效。
3. **A与Bi是否有额外交互**：分别计算四格交互差值，不能只看组合分数最高。

```text
I1 = (G04 − G01) − (G05 − G00)
I2 = (G08 − G01) − (G09 − G00)
I3 = (G13 − G01) − (G14 − G00)
```

四格差值按种子计算，再汇总。持续正向只能作为当前协议下的交互线索；不把它自动写成已证明的协同或独立测试收益。A内部“1:1 / SR2”的既有消融原样引用，不重复训练。

不同B之间的参数量和计算不同，比较的是候选整体性价比；参数完全匹配的机制结论只在各自路线内部做。3个种子、1个数据集不足以支持SOTA、显著性或跨区域泛化结论。选出后续候选也属于对该测试反馈的探索，不能重新称作独立确认。
