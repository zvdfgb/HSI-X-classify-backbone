# 局部／全局通道分工与 SR 的作用分析

日期：2026-11-04。15 个历史模型的只读诊断已完成；新对照训练已完成 6/6。全部产物已核验。

## 当前可以说清的结论

**SR 的独立收益比通道分工更稳定；组合有收益，但稳定互补尚未成立。** 历史完整训练中，SR 独立提高 1.0904 个百分点，三个种子均为正；分工独立平均为 −0.0273 个百分点，波动明显。组合相对纯 SSM 提高 2.3366 个百分点，三个种子均为正，但相对“仅 SR”只有两个种子为正。

分工更像是在改变类别间的取舍。它使高速公路召回率平均提高 12.387 个百分点，三个种子都改善；道路、铁路分别下降 11.143、9.677 个百分点，三个种子都受损。因此目前不能把它描述成普遍提高表征能力。逐样本看，分工独立有 15 个样本在三个种子中都被纠正，103 个样本在三个种子中都被改错；SR 独立则分别为 94 和 21。这里只比较固定样本集合上的结果，不代表独立样本显著性检验。

**SR 的权重筛选作用有直接证据，但“稳定改善边界”不成立。** 在 854 个标签覆盖足够的混合邻域中，已知异类邻居的平均权重质量由均匀汇总的 14.41%、仅距离的 6.73%，降至 SR 的 0.75%；中心平均权重仅 6.06%，有效邻居约 62 个。然而分工上加 SR，在这一邻域分层中的平均 OA 变化为 −1.913 个百分点，种子间分别为 −7.963、+0.585、+1.639。光谱相似性筛选与真实类别边界改善不是同一件事，不能只凭好看的权重图推出后者。

SR 独立在混合邻域、没有观察到异类且标签覆盖足够的邻域、标签覆盖不足邻域中的平均 OA 变化，分别为约 +1.288、−0.826、+3.788 个百分点。分层与类别、地物空间分布可能相关，不能认定“标签少导致 SR 更有效”；附表保留了类别×邻域分层的得失，供核查混杂因素。

进一步拆分后，这854个混合邻域只覆盖7个类别。seed6 在其中的109个受胁草地样本净少判对82个，主导了该种子的负增益；seed7／8在这109个样本的净变化为零。跑道混合邻域则每个种子都净少判对6个。这个负结果既不能被忽略，也不能泛化成“SR普遍损害所有边界”。后续应优先解释受胁草地的种子敏感性，以及跑道的稳定小幅退化，而不是继续泛泛画权重热图。

**末端汇总本身有作用，训练适配也可能参与。** 在没有 SR 的分工模型上，仅推理时换为正确 SR 就能平均提高 0.727 个百分点；只取中心也能提高 0.721 个百分点，两者相近。对经过 SR 训练的组合模型，改成只取中心反而平均下降 0.618 个百分点，改成均匀汇总下降 0.978，权重固定错位下降 2.968。这说明训练好的组合模型利用了中心以外的位置，但不能把完整训练的 +2.364 全部归因于末端一次加权操作。

三个种子的 SR 权重统计相同，原因是同一数据、同一 PCA 方案和固定 SR 参数；它们不是三份独立的机制验证。两路关闭干预均掉点，只证明当前模型依赖两路；究竟混合算子是否比统一算子更好，仍以六次完整训练结果为准。

还应结合已经完成的 P01／P02 实验：在末端正确 SR 保持不变的基础上，把正确 SR 先验额外送进注意力，平均仅提高 0.0547 个百分点，相对固定错位先验也只提高 0.0519。方向都是3/3为正，但对应的样本数很少。这不能概括成“SR放在融合前后完全等价”，因为它测试的是保留末端SR后额外加入注意力先验；目前只能说，提前注入尚未明显放大两个点的互补。参见[原批次报告](../results/sr_lg_prior_seed678_20261103/实验报告.md)。本次没有重跑或扩展该批次。

## 先明确两个模块究竟做了什么

局部／全局分工位于 HSI 特征提取阶段。每个块先经过原有 SSM，然后把 64 个通道固定分成两半：前 32 个经过注意力，后 32 个经过局部深度卷积，再拼接、投影并加外层残差。两个块采用同样结构。这里的“全局”指当前 11×11 窗口内的交互，不是整幅遥感影像；也没有对 LiDAR 分支进行同样的双路分工。

M0“纯SSM”是本项目消融名称，仍保留输入卷积、辅助模态卷积、融合层和分类头，只是不增加那两路算子。历史预检中M0／M2均为69,431个参数，M1／M3均为80,887个参数：分工增加11,456个参数，约16.5%；SR不增加可训练参数，但存在计算邻域权重的开销。这是评价收益与复杂度时需要同时交代的背景。

还要区分“使用不同算子”与“信息已经被严格分离”。两路输入都已经经过 SSM，局部卷积那一路也可能带有长程上下文；固定取前后32个通道，没有额外约束保证它们分别只包含全局／局部信息。因此论文宜称“局部与窗口全局算子的固定通道分工”，暂不能称为已证明的严格信息解耦，也没有证据证明这两半通道天然互不重复。

SR2 位于 HSI 与 LiDAR 特征拼接、卷积融合之后，替换最后的平均汇总。它根据输入 HSI 邻域与中心的距离、光谱差异生成 121 个位置权重，再用这些权重汇总融合特征。权重本身没有可学习参数，不使用标签，也不随骨干网络的训练改变。光谱差异在本项目 PCA 后的输入空间中计算。

所以，可以提出这样的工作假设：分工模块负责产生特征，SR 负责选择汇总哪些位置；假设是否成立，需要同时观察独立贡献、组合贡献、分类得失和干预结果。

## 本次分析的证据顺序

1. 复用 M0 纯 SSM、M1 分工、M2 纯 SSM＋SR、M3 分工＋SR、M4 分工＋仅距离汇总，各 seed6／7／8，核验 15 个历史 checkpoint 与报告。
2. 使用原数据入口重新推理，保留逐样本预测；比较纠正数、引入错误数、类别与有标签邻域分层。
3. 固定已有 checkpoint，替换最后汇总权重或关闭分支，观察模型依赖什么。这是诊断干预，不能当作重新训练的消融成绩。
4. 只补已明确列出的两类算子对照：两路局部 LL、两路全局 GG，各三个种子，共六次训练；复用原混合分工 LG＋SR 的三个种子作为参照。

所有训练仍调用 `scripts/train.py`，使用原始数据、优化器、100 轮训练、指标与测试 OA 选模规则。历史 checkpoint、报告和数据保持不变。

## 怎样判断互补、重复与冲突

交互增益定义为 `OA(M3) - OA(M1) - OA(M2) + OA(M0)`。正值表示本组结果中组合收益高于两项独立收益之和，负值表示低于。三个种子只能提供初步线索，不能由均值为正就认定稳定协同。

逐样本还要区分：只有组合才判对；加入 SR 纠正了分工模型；加入 SR 反而改错；同一样本在不同种子中得失相反。这样才能解释均值变化背后是否存在稳定受益对象。

LL／GG 对照保留原 SSM、固定 32／32 分流、分支外围结构与 SR，只替换其中一路算子。第一路原有归一化和支路残差仍保留，第二路原有外围结构仍保留。因此它检验的是当前结构中的算子组合，不证明 1∶1 是最优比例，也不构成严格等参数量比较。

## 解释边界

- 原训练器按测试 OA 选择 checkpoint；本报告沿用该规则，不能称为独立测试结论。
- 目前只有 Houston2013 和三个种子，空间相邻样本不能当作大量独立重复实验。
- 邻域分层只使用已知标签做事后分析，未知标签不算异类；“没有观察到异类”不代表真实纯净区域。
- 分支置零会造成输入分布变化；掉点说明当前模型依赖该分支，不等于重新训练后该分支能贡献相同幅度的收益。
- 激活能量大小不代表因果贡献；固定位置错位仅是一项诊断，不覆盖所有错位情况。
- 当前逐样本分析以本次 checkpoint 推理为准。历史未保存逐样本预测，不能保证逐像素预测完全复现；seed7 的 M2 已观察到一个错误类别变化，OA、AA 不变，Kappa 仅有微小差异，完整差异单独留档。
- 原M0／M1使用不同mode，构造时随机参数初始化调用路径不同；同一个seed并不保证它们所有共享层的初始权重严格相同。原四格实验应作为整体模型消融解释。本次LL／GG对照专门固定了与原LG模型的共享参数初始化和全局随机数状态。

## 4. SR 实际在选择什么位置
