## 1. 研究问题与范围

固定 A0 为原始局部／全局固定 1:1 通道分工 + SR2，分别检验 CF-IPT、ISFuse、IID 的可迁移融合子机制。三方向独立，不相互堆叠；不把局部／全局分工作为本轮新增变量，不取消 SR，不扩展纯 SSM 基线。

本轮是**针对现有分类网络的子机制迁移实验**，不是三篇论文的完整复现。尤其 IID 仅检验分布一致化，不检验其线性分类映射与信息约束；结果不能代表完整 IID 是否有效。

原始依据：

- CF-IPT：[论文入口](https://openaccess.thecvf.com/content/CVPR2026/html/Ji_CF-IPT_Cross-Modal_Fusion_Interactive_Prompt_Tuning_of_Vision-Language_Pre-Trained_Model_CVPR_2026_paper.html)、[作者仓库](https://github.com/Jiahuiqu/CF-IPT)、[本轮核对的融合源码](https://raw.githubusercontent.com/Jiahuiqu/CF-IPT/main/CF-IPT/Mutil_prompt_CLIP/MutilCLIP.py)。迁移空间／通道跨模态交互及多尺度融合，不引入 CLIP、文本、提示学习或预训练权重。
- ISFuse：[论文](https://arxiv.org/html/2603.23272v1)、[作者训练源码](https://raw.githubusercontent.com/wang-x-1997/Multi-Modal-Image-Fusion-via-Intervention-Stable-Feature-Learning/main/Train.py)。迁移 CFI 门控与干预一致性，不引入图像重建目标；本轮不使用存在解释方向疑点的 necessity 项。
- IID：[ICLR 2026 正式入口](https://proceedings.iclr.cc/paper_files/paper/2026/hash/c555e1ebfe943237aa8350442315d4a1-Abstract-Conference.html)、[全文](https://proceedings.iclr.cc/paper_files/paper/2026/file/c555e1ebfe943237aa8350442315d4a1-Paper-Conference.pdf)。迁移 Wasserstein 分布一致化及其稀疏频域投影思路。作者未提供经本轮核实的公开实现，求解细节采用下文明确写出的本地实验定义。

## 2. A0 与统一接入位置

复用 `NeighborTransMixer(variant="SR2", mode="decoupled")`：hidden_dim=64，num_blocks=2。HSI 经过原 stem、投影和两层解耦 block；LiDAR 经过原 aux_stem。LiDAR 没有与 HSI 对称的深层 block，本轮不补造该分支。

```text
HSI → 原 stem / 投影 / 两个固定1:1局部全局block → H [B,64,11,11]
LiDAR → 原 aux_stem                         → L [B,64,11,11]
                                  ↓ 本轮新增模块（各方向独立）
                         [H',L'] 或 128通道融合特征
                                  ↓
             原 fusion_conv(128→64) → 原 SR2 → 原非线性分类头
```

模块包裹既有 fusion_conv；原 fusion_conv 本身及后续 SR2、分类头保持原实现。新增模块走标准 adapter 接口，不复制训练器、数据加载器或评价代码。

SR2 保持 spatial_sigma=3.0、spectral_scale=0.2775005102157593。权重仍由原始 PCA 输入计算；ISFuse 的特征干预不得重新计算 SR 或污染输入。

A0 的 seed6/7/8 历史结果拟复用 `sr_native_20261029` 的 M3 三项。执行前必须核验配置、训练协议、原报告、checkpoint 哈希及复用链；不能核验则先报告问题，不自动补跑。A0 仅在文档中改名，旧产物不重命名、不重写。

## 4. CF-IPT 迁移定义

保留作者 CrossAttentionModule 的两个关系方向：空间关系作用于 LiDAR 更新，通道关系作用于 HSI 更新；维度统一为64，保持作者实际矩阵乘法方向，不擅自替换为另一种标准双向 MHA。只纳入真正参与前向的参数，不复制公开代码中的闲置层。

后续拼接为128通道。单尺度使用3×3卷积分支；多尺度使用1×1、3×3、5×5三个分支，并对分支输出取平均，以避免单纯叠加倍数成为变量。分支内沿用作者 Conv→ReLU→BN→Dropout(0.1) 次序。输出仍为128通道，随后进入原 fusion_conv。

公开实现的权重张量为 `[B,C,1,1]`，却使用 `softmax(dim=-1)`；该轴长度为1，权重恒为1。因此本地自适应版本明确改为 `g = C * softmax(a, dim=1)`，使通道平均权重为1；固定版本 `g=1`。这是**显式归一化修正和尺度适配**，不是原代码逐字复现。C01/C02 对应没有有效自适应通道选择的控制情形。

本轮不单独证明跨模态交互本身优于等容量卷积；C01-A0 仅代表新增结构包的效果。多尺度组参数更多，不能把 C02-C01 或 C04-C03 全归因于感受野。记录有效可训练参数、MACs、峰值显存及推理耗时，保留该归因限制。

预定比较：C04-A0；C02-C01；C03-C01；C04-C02；C04-C03；交互项 `(C04-C02)-(C03-C01)`。交互项只是本设置下多尺度与门控的经验非加性，不是统计显著性或因果结论。

## 5. ISFuse 迁移定义

仅在现有融合位置设置一层 CFI，不移植作者多尺度 U-Net。新交互部分为双向 cross-attention：64维、4头，K/V 自适应平均池化为4×4，Q保留11×11；新模块不含 BN 或随机 Dropout，避免干预多视图更新归一化统计或引入额外随机不一致。

令 `C` 为两个方向 cross-attention 输出之和，`L0=H+L`，`G=sigmoid(Conv3x3(C))` 为单通道空间门控：

```text
Y = G*C + (1-G)*L0
R = Y-L0
H' = H+R/2
L' = L+R/2
```

这样把 CFI 的融合修正回注两模态，保留原始模态差异及128通道原 fusion_conv 接口。该回注方式是本网络的显式适配，不属于原图像重建结构。S01仅将G固定为0.5；其余相同。固定门控不包含无效门控头；如实记录参数差，S02-S01不能描述为严格等容量比较。

S03/S04 使用完全相同的两类训练特征干预：

- 互补遮挡：每个样本分别为H、L选取一个互不重叠的3×3块，置零；两个块均不包含中心位置。
- 同位置随机遮挡：每个样本在两个模态上将相同的3×3非中心块置零。

每个训练 batch 使用干净视图和上述两种视图。掩码由独立 Generator 按训练seed、epoch、batch确定，同种子S03/S04共享规则；不消耗原数据增强、shuffle或网络Dropout的随机数流。没有额外数据、伪标签、测试集拟合或整模态丢弃。

原 backbone 只执行一次，原 fusion_conv、SR及分类头只在干净视图执行一次。干预只重复新 CFI 子模块，以其64通道输出Y做辅助一致性，不能为此重复原 backbone、修改原 BN 统计。评估关闭干预，仍走干净输入及原指标代码。

设 `D_v` 为干预输出与 `stopgrad(Y_clean)` 的逐位置通道平均绝对差，再除以干净输出的逐位置通道RMS加1e-6。该归一化只是本轮固定的特征尺度适配：

```text
S03: loss = CE + 0.1 * mean_views(mean(D_v))
S04: loss = CE + 0.1 * mean_views(
        mean(G_v*D_v)
        + 0.1*abs(mean(G_v)-0.3)
        - 0.05*mean(binary_entropy(G_v)))
```

门控正则逐样本计算后取batch均值。所有权重为本轮事先固定的探索性设置，不表示原论文在本任务的最优参数，也不运行搜索。S04-S03检验的是“加权一致性+门控约束”整体，不能再细分两项各自贡献。S02/S03/S04有效可训练参数一致。

原论文涉及融合图像重建，与本任务的分类输出不同；不搬入强度、梯度、SSIM损失。公开 necessity 实现将两个正 L1 距离相加，不能据此解释为最大化模态必要性，故本轮不使用。不能将S04成绩表述为完整ISFuse复现或已证明因果融合。

预定比较：S04-A0；S02-S01；S03-S02；S04-S02；S04-S03。额外记录干预辅助损失、门控均值／熵、两模态梯度范数和训练耗时。

## 6. IID 分布一致化迁移定义

原网络是 concat→卷积→SR→非线性MLP，不满足直接照搬论文线性共享分类映射的条件。本轮不替换原分类头、不实施信息约束IC，也不把论文理论保证直接套到本网络。

I01-I04均在原融合前设置两个独立1×1投影：64→64，bias=True，权重恒等、偏置0初始化；新增有效参数共8320个。两模态投影后的特征都进入原 fusion_conv，避免增加只服务辅助损失、主预测完全不用的旁路。

仅为计算辅助损失，用原SR权重分别池化投影后的两模态特征，得到两个 `[B,64]` 向量，再分别L2归一化。主预测仍使用完整投影特征，原最终SR读出保持不变。所有辅助统计只来自当前训练batch。

```text
I01: loss = CE
I02: loss = CE + 0.01 * (mean((mu_H-mu_L)^2)
                              + mean((cov_H-cov_L)^2))
I03: loss = CE + 0.01 * UOT(z_H,z_L)
I04: loss = CE + 0.01 * UOT(project(sparse_fft(z_H)),
                            project(sparse_fft(z_L)))
```

I02协方差使用batch样本协方差。I03/I04均采用同一熵正则非平衡OT定义：欧氏距离代价，均匀经验边缘；最小化 `sum(T*C)+eps*KL(T||a⊗b)+rho*KL(T1||a)+rho*KL(T^T1||b)`；eps=0.05、rho=1.0，log域Sinkhorn固定50次，全部步骤参与反向。该目标是明确的本地求解适配，不宣称逐字复现作者实现。

I04沿64维通道向量做FFT，不是图像二维频率融合。保留DC及Nyquist项，再按能量保留15个共轭频率对，其余置零，逆FFT还原64维实向量，然后用固定共享高斯矩阵投影到32维。高斯矩阵元素为N(0,1/32)，独立Generator seed20261104生成，注册为不可训练buffer，全部训练seed共用；不扰动训练随机数流。两个模态共享坐标映射，避免无关坐标系造成额外偏差。投影仅参与损失，不减小主预测特征维度。

不对投影输出再次单位归一化，以保留投影前后的距离尺度；记录原64维与投影32维的代价分布及数值范围。不得将随机矩阵直接称为已在本数据上证明满足RIP，不保证64→32一定更快。I04-I03同时包含频率筛选和降维，不能拆分其单独贡献。

预定比较：I04-A0；I01-A0；I02-I01；I03-I01；I04-I01；I04-I02；I04-I03。I01-I04主干及投影参数完全相同；这几项比较可以排除“只是多了投影参数”的解释。所有结论仅针对所定义的DC迁移。

## 8. 结果判读与报告

必须报告39项逐种子OA/AA/Kappa、13组均值±样本标准差(ddof=1)、预定比较的同种子差值、平均差值和正增益次数；OA差值用百分点。另列AA、Kappa和原每类精度、有效参数、显存、训练总耗时／每轮耗时、干净推理耗时。

主比较固定为C04-A0、S04-A0、I04-A0。结构控制组结果即使更好也如实报告，属于次要发现，不替换主比较。检查所有100轮完成证据、原报告／checkpoint／日志及哈希后才汇总最终成绩；中间测试OA不能当最终结果。

判读规则：

1. 候选高于A0，且高于其关键控制组，才支持该指定子机制在当前网络中有增益线索。
2. 候选高于A0、但不优于控制组：只支持新增结构或一般正则可能有用，不能归因于论文独特机制。
3. OA未提升、但参数／耗时下降：单独讨论效率价值；不包装成精度提升。
4. 均值下降或种子正负混合：报告当前固定设置下未验证增益；不能宣布整篇论文或所有迁移配置不可行。
5. 三种子同向也不自动等于显著、稳定或可泛化。本方案仍是单数据集、有限种子、测试OA参与选模的探索，不是独立测试证据。

三个方向计算量不同，尚未构建或运行本方案，**不承诺具体训练小时数**。用户批准后，仅在完成接口核验及获准执行首组后，用真实耗时给出剩余时间估计，不为估时额外训练。
