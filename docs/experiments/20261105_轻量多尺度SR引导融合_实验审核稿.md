## 1. 设计背景与问题定位（基于 `fusion_transfer_v3` 实证诊断）

在前期已完成的 9 条外部论文融合子机制迁移实验（`B1/B2/B3`、`F/U/D`、`C/S/I`）中，仅 `C02`（CF 跨模态交互 + `1×1/3×3/5×5` 多尺度分支，无通道门控）在三种子平均 OA 上显著高于基线 `A0`（`90.8256%` vs `89.3990%`，平均 `+1.4266` 个百分点），且多尺度相对单尺度（`C02 - C01` 为 `+0.9319`、`C04 - C03` 为 `+0.7352`）在三个种子上全部同向为正。

但原生 `C02` 与 `C04` 不能直接作为论文创新点，日志与逐类指标暴露了三个具体机制缺陷：

1. **密集大核参数膨胀导致小样本早熟过拟合**：`C02` 参数量达 `680,311`（`A0` 的 `8.41` 倍），其中单个密集 `5×5` 卷积（`128→128`）即占 `409,728` 参数、`3×3` 占 `147,584` 参数。在 Houston2013 仅 `2,832` 个训练样本上，`C02` 在第 20–30 轮即快速拟合并见顶（`seed6` 与 `seed8` 均在第 30 轮达到峰值后回落），难以排除“靠 8 倍参数容量涨点”的审稿质疑。
2. **缺少外层恒等残差且多尺度固定均分，导致细长地物边界模糊**：原生 `C02` 直接用 `1×1/3×3/5×5` 三分支均值覆盖融合前特征，无外层残差保护。虽然大尺度地物（如 `Highway`、`Commercial`）提升明显，但细窄线性地物 `Road`（`1,059` 个测试样本）在三个种子上全部退化（平均 `-3.31` 个百分点），且 `seed6` 整体掉点 `-4.12` 个百分点。
3. **全通道 `softmax` 竞争门控引发单通道坍缩**：`C04` 的 `128 * softmax(dim=1)` 在训练中出现 `channel_gate_max ≈ 128.0`（其余 127 个通道趋近 `0`），造成 `parking lot 2` 等类别召回率暴跌 `-14.39` 个百分点。

## 2. 拟定融合创新点：同质性感知的非对称多尺度融合（HAMF）

围绕本研究既有的 **“深层局部/全局 HSI 主干 + 浅层 LiDAR 支路 + 末端 `SR2` 邻域相似性读出”** 架构，提出轻量化融合模块，由三个紧扣物理动机的子部件组成：

```text
HSI 深层特征 H [B,64,11,11] ──┐
                              ├─► (1) 缩放残差非对称双向互导 ─► X0 = concat[H',L'] [B,128,11,11]
LiDAR 浅层特征 L [B,64,11,11] ─┘                                        │
                                                                        ▼
原输入无参数 SR2 权重图 W_sr [B,1,11,11] ──► (3) SR 同质性引导像素级尺度门控 (w1, w3, w5)
                                                                        │
                                                                        ▼
                              X_out = X0 + gamma * (w1*B1(X0) + w3*B3(X0) + w5*B5(X0))
                                                                        │
                                                                        ▼
                                         原 fusion_conv(128→64) ─► 原 SR2 ─► 原分类头
```

### 2.1 子部件一：缩放残差非对称跨模态互导（针对模态深浅不对称）

HSI 分支经过 3D 卷积与两层局部/全局解耦块，语义深但易受云影干扰；LiDAR 分支仅经过一层浅层 `3×3` `aux_stem`，高程几何不受光照影响但缺乏长程语义视野。

- 共享值映射：`[Vh, Vl] = chunk(Conv1x1(128→128)(concat[H, L]), 2)`。
- **HSI 通道校准（`64×64`）**：`A_ch = softmax((H_flat @ L_key_flat^T) / sqrt(121), dim=-1)`，以高程空间分布一致性校准受阴影干扰的光谱通道：`H' = H + alpha_h * reshape(A_ch @ Vh)`。
- **LiDAR 空间聚合（`121×121`）**：`A_sp = softmax((L_flat^T @ H_key_flat) / sqrt(64), dim=-1)`，借深层光谱语义聚合窗口内同类地物高程上下文：`L' = L + alpha_l * reshape(Vl @ A_sp)`。
- 与原生 CF-IPT 的关键区别：加入标准点积维度缩放（`1/sqrt(121)` 与 `1/sqrt(64)`）防止初始注意力饱和，并引入可学习标量残差系数 `alpha_h, alpha_l`（初值 `0.1`），保证训练初期平稳继承 `A0` 特征分布。

### 2.2 子部件二：保边残差深度可分离多尺度分支（减重 90%+ 并保住细小目标）

令 `X0 = concat[H', L']`（`[B, 128, 11, 11]`）。用深度可分离卷积替代原生 `C02` 的密集大核卷积，设置 `k in {1, 3, 5}` 三条并行分支 `B_k(X0)`：

- 每条分支结构统一为：`DWConv2d(128, 128, kernel_size=k, padding=k//2, groups=128, bias=False) → BatchNorm2d(128) → ReLU → PWConv2d(128, 128, kernel_size=1, bias=False) → BatchNorm2d(128) → Dropout(0.1)`。
- 三条分支合计参数仅 **`55,168`**（原生 `C02` 三条密集分支为 `574,592`，**多尺度分支参数削减 `90.4%`**；整网总参数从 `680,311` 降至约 **`163k`**，仅约 `C02` 的 `24%`）。
- **外层保边残差**：输出定义为 `X_out = X0 + gamma * F_ms(X0)`，其中 `gamma` 为通道维可学习缩放向量 `[1, 128, 1, 1]`（初值 `0.1`），确保 `1×1` 清晰中心像素特征不被大核卷积覆盖。

### 2.3 子部件三：`SR` 邻域同质性引导的像素级尺度选择（消除通道坍缩并与主线统一）

摒弃 `C04` 在 128 个通道上竞争的 `128 * softmax(dim=channel)`，改为在 **`3` 个空间尺度（`1×1`、`3×3`、`5×5`）上做像素级软选择** `w = [w_1, w_3, w_5]`（形状 `[B, 3, 11, 11]`，满足 `w_1 + w_3 + w_5 = 1` 且 `0 < w_k < 1`，全部 128 个特征通道完整保留，从根源上杜绝单通道坍缩）：

- **特征分支门控**：`U = (B_1 + B_3 + B_5) / 3`，经 `Conv1x1(128→16) → ReLU → Conv1x1(16→3)` 得到 `logits_feat`（末层权重与偏置零初始化）。
- **`SR` 同质性先验分支**：直接复用原网络已由输入 `hsi_pca` 计算好的无参数 `SR2` 权重图 `W_sr`（`[B, 1, 11, 11]`，`detach` 不传梯度、不使用任何标签）。因 `W_sr` 全窗和为 `1`（均值为 `1/121`），令归一化同质图 `S_1 = 121.0 * W_sr`，并计算其局部邻域均值 `S_3 = AvgPool3x3(S_1)`、`S_5 = AvgPool5x5(S_1)`，拼接为 `S = concat[S_1, S_3, S_5]`（`[B, 3, 11, 11]`）。
  - 物理含义：在细窄道路（`Road`）或异类交界处，周围邻域光谱差异大，`S_3, S_5` 显著低于中心，提示抑制 `3×3 / 5×5` 跨边界混叠、偏向 `1×1` 保边分支；在大片同质屋顶、水面或阴影连续区，`S_3, S_5` 平缓充足，提示放大 `3×3 / 5×5` 多尺度抗噪上下文。
  - 映射：`logits_sr = Conv3x3(3→8) → ReLU → Conv1x1(8→3, bias=False)`（共 `248` 个参数，末层零初始化）。
- **合成权重**：`w = softmax(logits_feat + logits_sr, dim=1)`。由于末层零初始化，训练第 0 步严格满足 `w_1 = w_3 = w_5 = 1/3`，与固定均分对照起点完全一致。

## 4. 锁定协议与判读标准

1. **严格复用原训练与评估链路**：统一走 `scripts/train.py → src/runner.py → src/trainer.py`，数据与划分保持 Houston2013 官方划分（PCA30、`11×11`、100 轮、`batch=128`、AdamW `lr=1e-4`、`weight_decay=0.01`、`seed6/7/8`），评估走原 `src/evaluator.py` 与 `src/metrics.py`。保留按既定轮次测试 OA 保存模型的现有规则，如实说明选模口径，不包装为独立测试。
2. **隔离随机数流**：先完整初始化原 `NeighborTransMixer("SR2")` 主干并校验与 `A0` 共有参数初始哈希一致，再在 `fork_rng` 隔离环境中初始化新增融合模块；同种子的共有子模块（如 `M01–M05` 的互导层、`M02–M05` 的三尺度分支、`M03–M05` 的特征门控头）保持配对一致初始化。
3. **预设主比较与诊断指标**：
   - 主比较固定为 **`M04 - A0`**，核心消融链为 `M02 - M00`（跨模态互导）、`M02 - M01`（等容量多尺度）、`M04 - M02`（自适应尺度总作用）、`M04 - M03`（`SR` 同质性先验作用）、`M04 - M05`（正确空间对应证伪），并对比 `M04` 与 `C02` 的参数开销、第 30–100 轮收敛稳定性以及 `Road`、`Highway`、`Commercial`、`parking lot 2` 等关键类别召回率。
   - 额外保存训练与全测试集上 `w_1, w_3, w_5` 在不同类别（尤其是细窄 `Road` 与大块 `Commercial/Highway`）上的尺度权重分布统计，验证模型是否真正学会“窄目标偏 `1×1`、大片目标偏 `3×3/5×5`”的可解释行为（可直接用于论文可视化出图）。
