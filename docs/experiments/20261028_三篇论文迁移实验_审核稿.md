## 1 共同基线与统一条件

G0 = 当前 `TransMixer_B0_Decoupled`，也就是融合实验的F0：保留SSM、局部与全局固定1∶1通道分配、现有模态融合、平均汇总和分类头。这里的F0不是“去掉1∶1创新的原模型”。

F4是另一项双向交互改动，不是1∶1分配本身。本轮先不同时叠加F4、蒸馏、标签平滑，方便明确每条路线的额外贡献。候选通过后，再补“F4 / F4＋候选”的适配比较。

| 项目 | 本轮预设 |
| --- | --- |
| 数据 | Houston2013，HSI＋LiDAR |
| 输入 | PCA 30维，11×11窗口，判断中心类别 |
| 划分 | 沿用验证选模流程：官方训练中心中分层留20%验证；划分种子20261024；保存并复用同一份位置索引 |
| 预处理 | 沿用当前流程：无标签全场景PCA与标准化，预处理种子20261024；属于同场景设定，中心不交叉但邻域可能重叠 |
| 重复 | 每组种子6、7、8；同一种子的基础参数、批次次序和增强尽量配对 |
| 普通训练 | 100轮，AdamW，学习率0.0001，weight decay 0.01，batch size 128 |
| 选模 | 验证OA最高，平手取验证分类损失更低；各组使用同一规则，不按含辅助项的总损失打破平手 |

## 2 第一轮：SSR启发的中心邻居选择

**问题：判断中心地物时，平均使用整个窗口会不会混入无关邻居？**

第一轮只替换最后的空间平均汇总，保持SSM读取顺序不变。权重由输入的空间距离、PCA光谱距离和LiDAR差异计算，不增加可训练参数。

| 组别 | 网络组成 | 要回答的问题 |
| --- | --- | --- |
| G0 | 1∶1基线，窗口各位置平均汇总 | 共同起点 |
| SR1 | G0＋只按与中心的空间距离加权 | 单纯“近处更重要”是否就有帮助 |
| SR2 | G0＋空间距离与光谱相似度加权 | 光谱信息能否选出更有用的邻居 |
| SR3 | G0＋空间距离、光谱相似度与LiDAR差异共同加权 | LiDAR能否在光谱选择上提供额外帮助 |

每个位置的最终融合特征乘其权重，再加总；所有位置权重之和为1。三组都从输入计算权重，输出维度及分类头相同。

首版固定方式：空间权重用高斯距离，尺度3像素；光谱距离用PCA各维差的均方，LiDAR用高度差的平方；两个数据距离各自除以训练窗口非中心位置距离的中位数，并设置数值下限。加入相应负距离后用softmax归一化。距离尺度仅由训练输入估计，不逐组搜索。

重点比较：`SR1−G0`、`SR2−SR1`、`SR3−SR2`，同时记录SR3相对G0的总变化。若SR1最好，就保留“空间先验有效”的结论；若SR3超过SR2，才支持本配置中两模态共同选择邻居的价值。

这一步验证区域选择的前提，并未验证SSR式重排扫描。只在出现正向信号后补两组：

- SCAN_A：在SR3上，SSM改用固定几何分组顺序。
- SCAN_B：在SR3上，SSM改用两模态共同生成的分组顺序。

两组均固定4组、保持组内原空间顺序、扫描后恢复原位置，保持SSM参数与SR3汇总方式一致；本轮不同时增加区域门控或状态重置。SCAN_B对SCAN_A检验内容分组是否优于固定分组，SCAN_A/SCAN_B对SR3检验改变扫描顺序的影响。

## 3 第二轮：PnP启发的融合后纠偏

**问题：原模型融合后，小网络能否利用两个模态保留的信息修正判断？**

先获得每个种子的G0最佳验证检查点，再固定整个G0。HSI分支、LiDAR分支和融合后的特征各平均汇总成64维，记为h、a、z。纠偏器输出64维修正量，加到z上，再通过原来的分类头。

| 组别 | 网络组成 | 要回答的问题 |
| --- | --- | --- |
| G0 | 原基线的固定检查点，不加纠偏器 | 不纠偏的成绩 |
| PN1 | 固定G0＋只看融合特征的普通纠偏器 | 增加一个小修正网络本身能改善多少 |
| PN2 | 固定G0＋同时看HSI、LiDAR与融合特征的纠偏器 | 额外查看分开的两模态是否值得 |

PN1和PN2均使用 `192 → 16 → 64` 的同一MLP结构，PN1输入拼接为 `[z,z,z]`，PN2输入为 `[h,a,z]`；参数量、初始化和训练预算完全相同。最后一层初始化为0，使初始预测等于G0。

第二阶段均训练50轮，使用同一训练集、分类损失与优化器设置。G0的参数和BatchNorm统计固定，Dropout保持评估状态；分类头也固定，只训练纠偏器。两组共享同一种子的同一G0检查点，不额外使用验证样本训练。

重点比较 `PN2−PN1` 和 `PN2−G0`。若两组都提升但相近，当前证据支持“小网络修正”，尚未支持额外读取两模态的优势。PN1提供同样的额外训练预算对照。

记录“原来错、现在对”和“原来对、现在错”的样本数。二者之差才是纠偏的净收益。

这里迁移的是分阶段纠偏思路，分类任务只修正一次。只有PN2表现值得继续时，再增加同结构端到端训练对照，检验“固定基线分开学”与“一起学”的区别。

## 4 第三轮：OceanCBM启发的可解释线索

**问题：明确学习两条有含义的几何线索，能否改善分类？让分类直接读取这些线索是否更好？**

第一版只取两条由输入LiDAR计算的线索：

1. 中心相对高度：中心值减去窗口平均值。
2. 局部高度起伏：窗口内高度的标准差。

它们是几何代理量，不直接当作“树木”或“建筑”标签。目标计算方式固定，仅用训练样本统计做目标标准化；其他划分复用该统计。

| 组别 | 网络组成 | 要回答的问题 |
| --- | --- | --- |
| G0 | 只学习地物分类 | 共同起点 |
| OC1 | G0＋两条线索预测，预测值不送给分类头 | 额外学习这些线索能否帮助原分类特征 |
| OC2 | G0＋两个普通学习值，并送给分类头，无线索监督 | 新增小分支与两个输入值本身的作用 |
| OC3 | 与OC2完全相同的网络，两个值接受线索监督，也送给分类头 | 有含义的线索监督是否比普通学习值更有效 |

线索预测头首版为 `64 → 2`。OC2/OC3的分类头均读取原64维普通特征与2维预测值；OC1仍使用原分类头。OC2/OC3网络与初始化配对，区别只有是否加入线索学习损失。

OC1/OC3的训练目标固定为“分类损失＋0.1×两条标准化线索的平均MSE”。OC2只用分类损失。所有组100轮，不在本轮反复试损失权重。推理时由模型预测线索，保留原64维普通特征通道。

重点比较 `OC1−G0`、`OC3−OC2` 和 `OC3−G0`。OC3与OC1的比较只作结构探索，因为它们的分类头输入不同。

同时检查线索预测误差是否好于“永远猜训练均值”。对OC3做一次将线索替换为训练均值的推理诊断，查看预测与准确率是否改变。该诊断用于了解模型是否依赖此通道。

若OC1有效、OC3不优于OC2，则优先保留“辅助线索学习”的路线；若OC3优于OC2且线索可预测，则值得继续研究有监督的线索参与分类。由于仍有普通特征通道，本设计是带概念支路的混合模型。

## 5 共多少组，按什么顺序执行

首批独立配置共9组：**G0、SR1、SR2、SR3、PN1、PN2、OC1、OC2、OC3**。

每组三种子，共27个训练任务。其中21个为100轮普通训练；6个为依附G0检查点的50轮纠偏训练，不需要重复训练6个G0。符合核验条件的基线检查点可减少重跑。

执行顺序：G0 → SR1/SR2/SR3并比较 → PN1/PN2并比较 → OC1/OC2/OC3并比较。三个方向即使前一轮没有收益，后一轮也仍然从G0开始验证。

SCAN_A/SCAN_B、PnP端到端对照、F4适配比较、去掉1∶1的独立作用消融，均属后续条件实验，不计入首批27个任务。先找出值得保留的单个候选，再决定是否组合。

## 6 怎样判断值得继续

- 主指标：验证OA，即全部验证样本中分类正确的比例；报告三种子的均值、标准差和每种子的配对差值。
- 辅指标：AA、各类别召回率、混淆矩阵、参数量、固定批次推理时间；纠偏路线另报两阶段总训练成本。
- 初筛：相对G0的平均验证OA为正，且至少2/3种子正向；声称具体机制有帮助，还要相对上述指定对照出现同方向收益。这是继续投入的筛选规则，不是显著性检验。
- 对初筛通过者，用新增种子9、10复核，并重跑相应G0和机制对照。五种子的汇总全部保留，不能只选好看的种子。
- 冻结候选与训练规则后，再统一计算G0、候选和必要对照的测试成绩，不按测试结果继续搜索。正式论文还应补空间分组验证或第二数据集。

标签未知的位置不用于类别混淆或真实边界统计。若做边界诊断，只在邻近位置都有有效参考标签的子集上汇报，并给出该子集大小。

第一轮的预处理、邻域重叠条件与当前验证流程一致，便于控制变量；空间隔离作为后续单独验证，不能把本轮称为跨区域泛化结果。
