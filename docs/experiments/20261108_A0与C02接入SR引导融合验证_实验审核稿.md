## 1. 实验动机与问题拆解

上一轮 `SR-NCF`（`K00–K06`）揭示了两个现象：
1. 在不含末端 `SR` 时，融合阶段引入 `SR2` 邻域引导在全部三个种子一致涨点（`K04 - K06 = +0.8718` 个百分点，`3/3` 全正）；
2. 但在 `K02`（`A0` + 共享空洞多尺度 `d=1, 2` + `SR2` 引导融合）中，同时叠加了“间隔采样空洞卷积”且缺少“双模态显式互导”，导致 `K02` 在 `seed7 / seed8` 上与均匀组 `K01` 基本打平。

为剥离空洞稀疏采样的干扰，并在“无跨模态互导（`A0`）”和“有跨模态互导 + 密集大感受野（`C02`）”两种典型基座上干净检验 `SR` 对特征融合的作用，设计双基座六组严格对称实验（`R00–R05`）：

- **为什么 `A0` 需要补一个最小 `3×3` 邻域分支才能加 `SR` 引导？**
  原 `A0` 的融合层 `fusion_conv` 仅有 `1×1` 逐像素卷积（无任何空间邻居，局部有效邻居数 `N = 1`，归一化权重恒为 `1.0`）。因此在 `A0` 上采用最简 **`1:1` 当前位置 `1×1(64)` 直连 + 密集 `3×3(64)` 跨通道邻域卷积**（不含 `d=2` 空洞稀疏采样），对比均匀权重（`R00`）、正确 `SR2`（`R01`）与仅融合错位 `SR2`（`R02`），同时免费复用上一轮已跑完的 `A0 + 紧凑多尺度 SR 融合`（`K01 / K02 / K03`）作同表参照。
- **为什么 `C02` 可以实现“`+0` 新增参数、同初值”直接接入 `SR` 引导？**
  原 `C02` 本身已包含 `1×1`（当前位置）、`3×3`（`9` 邻居）与 `5×5`（`25` 邻居）三条 `128` 维并行卷积分支，只是默认对所有邻居赋予均匀权重 `1.0`（导致细长 `Road` 召回率较 `A0` 下降 `-3.31` 个百分点）。保持 `C02` 的 `CrossModalRelations` 与 `b1(1×1)` 完全不变，直接将局部均值 `1.0` 归一化的 `SR2` 调制乘在 `b3(3×3)` 与 `b5(5×5)` 进入跨通道卷积前的每个邻居贡献上，即可在 **`0` 新增参数（同为 `680,311` 参数）且初始权重逐位一致**的条件下，干净对比均匀权重（`R03`）、正确 `SR2`（`R04`）与仅融合错位 `SR2`（`R05`）。

## 2. 精确算子定义与无混杂实现规则

### 2.1 任意奇数核尺寸 `k ∈ {3, 5}` 的有效邻居均值 `1` 归一化公式
设原生 `NeighborTransMixer` 入口无梯度算出的相对于窗口分类中心 `(5, 5)` 的一致性权重为 `W_sr`（形状 `[B, 1, 11, 11]`，全窗非负且和为 `1`；注意其物理含义是各像素相对于窗口中心 `(5, 5)` 的一致性权重，而非每像素自相似性）。对核尺寸 `k ∈ {3, 5}`（零填充 `padding = k // 2`）：
1. 令全 `1` 张量 `1_{1×1×11×11}` 经相同零填充 `F.unfold(..., kernel_size=k, padding=k//2)` 得到窗口内有效邻居掩码 `M_k(p, t) ∈ {0, 1}`（形状 `[1, k*k, 121]`），位置 `p` 的有效邻居个数 `N_k(p) = sum_{t} M_k(p, t)`（`k=3` 时取值 `4/6/9`；`k=5` 时取值 `9/12/15/20/25`）；
2. 在 `float64` 精度下计算局部有效邻居归一化调制权重（保留 `float32` 正常数域 `> 1e-37` 内全部比例，仅在局部全下溢 `<= 1e-37` 时回退有效位均匀 `1.0`）：
   - `S_k(p) = sum_{t'} M_k(p, t') * W(q_{t'})`
   - `alpha_k(p, t) = M_k(p, t) * N_k(p) * W(q_t) / S_k(p)`（当 `S_k(p) > 1e-37`），否则 `alpha_k(p, t) = M_k(p, t)`
3. 性质保证：
   - 越界零填充采样位 `alpha_k(p, t) = 0`；
   - 每个像素位置 `p` 上全部窗口内有效邻居的调制权重算术平均值恒为 `1.000000`，不改变分支信号幅度；
   - 当 `W` 取均匀先验 `1/121` 时，有效位 `alpha_k ≡ 1.0`，双精度实测与原 `C02` 的 `F.conv2d(..., bias=conv.bias, padding=k//2)` 最大绝对误差为 `1.61e-15`（`k=3`）与 `1.78e-15`（`k=5`）。
4. **消除 GPU 算子核差异**：`R00 / R01 / R02` 之间以及 `R03 / R04 / R05` 之间，均匀组与 `SR2` 组统一走完全相同的 `F.unfold + matmul` 代码路径（`R00` 与 `R03` 传入均匀 `1/121`），彻底消除 cuDNN `conv2d` 与 cuBLAS `matmul` 的 TF32 舍入混杂。

### 2.2 可核对伪代码

```python
def local_mean_one_kernel_weights(w_map, kernel_size, in_bounds_mask):
    pad = kernel_size // 2
    w64 = w_map.to(torch.float64)
    m64 = in_bounds_mask.to(torch.float64)  # [1, k*k, 121]
    n_valid = m64.sum(dim=1, keepdim=True)  # [1, 1, 121]
    w_unf = F.unfold(w64, kernel_size=kernel_size, padding=pad)
    w_valid = w_unf * m64
    denom = w_valid.sum(dim=1, keepdim=True)
    alpha64 = torch.where(denom > 1e-37, m64 * n_valid * w_valid / denom.clamp_min(1e-300), m64)
    return alpha64.to(dtype=w_map.dtype).unsqueeze(1)  # [B, 1, k*k, 121]

def sr_modulated_conv2d(x, conv_layer, in_bounds_mask, w_fusion):
    b, c_in, h, w = x.shape
    c_out = conv_layer.out_channels
    k = conv_layer.kernel_size[0]
    alpha = local_mean_one_kernel_weights(w_fusion, k, in_bounds_mask)  # [B, 1, k*k, 121]
    x_unf = F.unfold(x, kernel_size=k, padding=k // 2).view(b, c_in, k * k, h * w)
    x_mod = (x_unf * alpha).view(b, c_in * k * k, h * w)
    out = (conv_layer.weight.view(c_out, c_in * k * k) @ x_mod).view(b, c_out, h, w)
    if conv_layer.bias is not None:
        out = out + conv_layer.bias.view(1, c_out, 1, 1)
    return out
```
